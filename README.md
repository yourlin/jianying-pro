# jianying-pro | 让 AI 用剪映专业版 11.x 替你剪辑

一个给 AI 编程助手（Claude Code / Cursor / Trae / Antigravity）用的 Agent Skill。你用自然语言描述想要的视频，AI 调用本 skill 生成**可以直接在剪映里继续编辑的草稿**，包括时间轴、字幕、配音、配乐、特效、调色、美颜、模板，以及剪映 11.x 面板上的几乎所有功能。

## ✨ 优势

- **跟上剪映 11.x**：素材面板、美颜美体、AI 画质、智能打光、字幕模板等写法，都是对照剪映 11.7 自己保存的草稿逐个字段核对过的，而且**每项功能都在剪映里打开验证过**。剪映升级后，可以运行 `tools/audit_jianying_compat.py` 检查有没有新的草稿格式变化。
- **素材全覆盖**：建好了剪映本地面板的完整索引，共 **40 个索引、约 6.2 万条**素材（见下表）。AI 可以按名称、分类搜索，也可以分开免费 / VIP 素材。
- **先看封面再选**：贴纸、特效、模板等看得见的素材，AI 会先生成封面对比图，看过再选，不是只凭名称（如「KkQ1-4」）猜效果。动画类素材会从动图里抽帧。
- **字幕模板全部可用**：面板上的 **1,725 个字幕模板**（免费 345 + VIP 1,380）都生成了预设，可以直接套用，不用先在剪映里手动点一次。
- **剪映内截图检查**（macOS）：生成草稿后，AI 可以在剪映里打开草稿、定位到指定时间，截取播放器画面，确认渲染效果。
- **模板化批量出片**：以一个草稿为母版，替换素材槽位，批量生成新草稿；素材丢失时能自动重连。
- **安全可控**：
  - 只读取剪映的本地缓存和草稿，不修改剪映自己的数据（导入 LUT 时登记 LUT 库除外，会先做备份）。
  - 不在剪映外下载或合成 VIP 内容，VIP 素材照样能写进草稿，导出时由剪映检查会员。
  - 不破解剪映加密的草稿。剪映原生草稿通过明文的 `template.json` 只读访问，要编辑就先克隆成新草稿。

## 🚀 安装

```bash
# Claude Code（其他编辑器把目录换成 .cursor/skills、.trae/skills、.agent/skills 等）
git clone git@github.com:yourlin/jianying-pro.git ~/.claude/skills/jianying-pro

# Python 3.12 虚拟环境
python3 -m venv ~/.venvs/jianying
~/.venvs/jianying/bin/pip install -r ~/.claude/skills/jianying-pro/requirements.txt
~/.venvs/jianying/bin/playwright install chromium   # 只有「网页动效转视频」需要

# 可选：本地 AI 字幕
~/.venvs/jianying/bin/pip install faster-whisper==1.2.1 "av<16"

# 同步本机剪映素材（只读）
~/.venvs/jianying/bin/python ~/.claude/skills/jianying-pro/scripts/jy_wrapper.py sync
```

- **剪映**：剪映专业版 11.x（在 macOS 11.6 / 11.7 上验证过）。草稿目录会自动探测：
  - macOS：`~/Movies/JianyingPro/User Data/Projects/com.lveditor.draft`
  - Windows：`%LOCALAPPDATA%\JianyingPro\User Data\Projects\com.lveditor.draft`
- **ffmpeg**：响度统一、媒体解析兜底时会用到。
- **macOS 权限**（只有剪映内截图检查需要）：系统设置 → 隐私与安全性，在「屏幕录制」和「辅助功能」里勾选运行 AI 助手的终端或应用。

## 🐍 直接用 API

```python
from jy_wrapper import JyProject

p = JyProject("周末露营", overwrite=True)
v = p.add_media_safe("camp.mp4", 0, "8s")
p.add_text_simple("周末露营记", 0, "3s", subtitle_template="口播-可爱手写体蓝白色")   # 免费模板
p.set_adjust(v, 色温=-15, 饱和度=10)
p.set_beauty(v, 磨皮=40, 瘦脸=30)
p.set_smart_relight(v, "氛围暖光")
p.set_loudness_normalize(v, target_lufs=-14)
p.save()
p.preview(at=[1, 5])   # macOS：在剪映里截图检查
```

完整 API 和每个功能的写法见 [rules/jianying-11.md](rules/jianying-11.md)，给 AI 的执行流程见 [SKILL.md](SKILL.md) 和 [docs/agent-playbook.md](docs/agent-playbook.md)。

## ⚠️ 限制

- **验证范围**：剪映 11.x 的功能都在 **macOS** 上验证过。Windows 能生成草稿，但 11.x 新功能没有在 Windows 上逐项验证。
- **不支持**：CapCut 国际版、手机版剪映。
- **导出**：自动导出只支持 Windows 上的旧版剪映（5.9 及以下）。macOS 需要在剪映里手动导出。
- **剪映原生草稿是加密的**：skill 只能只读访问。要编辑就先 `clone` 成新草稿。
- **新草稿刷新**：剪映首页不会自动刷新出新生成的草稿。从编辑页回首页，或切到「模板」再切回「首页」，就会刷新出来。
- **VIP 素材**：VIP 素材可以写进草稿，导出时剪映会检查会员。
