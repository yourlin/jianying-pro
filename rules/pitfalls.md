# 实战踩坑记录

来源：2026-11-10「小狸试卷网页版宣传片」（竖屏 58 秒广告式宣传片，录屏 12 段 + 解说 29 句 + 配乐卡点 + 贴纸音效）。
每条写明 **症状 / 根因 / 现在的处理**。标 ✅ 的已在 skill 代码里修复并有回归测试（`tests/test_draft_safety.py`），
标 ⚠️ 的需要按规程操作。

## A. 草稿反复重建（最多、最难查）

### A1 ✅ 素材库里一大串「媒体丢失」，但时间线能播
- **症状**：剪映打开后素材面板出现几十到上百条 `tts_xxxxxxxx.ogg 媒体丢失`，数量随重建次数累积；时间线本身正常。
- **根因（两层）**：
  1. 草稿模板里写死了草稿 ID（`BC69C7CD-…`）和时间线 ID（`91E08AC5-…`），所有 skill 草稿共用一对 ID；剪映按 ID 缓存素材记录，会把别的 / 旧的草稿的素材串进来。
  2. 剪映还**按草稿路径**记住素材库列表。重建时删掉整个文件夹（连旧配音文件一起删），配音又是随机文件名，重新打开时剪映去找已删除的旧文件。
- **现在**：`create_draft` 每个新草稿生成随机草稿 ID / 时间线 ID；覆盖重建时**保留** `materials/`、`temp_assets/`、`Resources/`，只清掉其他文件；配音文件名按 `(音色, 文本)` 固定。
- **历史草稿**：旧版 skill 生成、已被污染的草稿无法从外部清理（剪映打开后文件已加密）。换一个草稿名重新生成即可（新路径没有旧缓存）。

### A2 ✅ 剪映里看到的一直是旧版
- **症状**：重新生成后，剪映打开的还是上一版（旧标题、旧素材名）。
- **根因**：剪映 11 首次打开草稿时会另存一份时间线 `Timelines/<id>/draft_info.json`，之后优先读它；只覆盖外层 `draft_info.json` 不生效。
- **现在**：覆盖重建会清掉 `Timelines/` 等剪映生成的文件（素材目录除外）。

### A3 ✅ / ⚠️ 剪映关闭编辑器时把新草稿覆盖成旧版
- **症状**：生成成功、校验通过，剪映一打开又是旧内容 / 媒体丢失。
- **根因**：剪映**正打开着**这个草稿时，关闭编辑器（包括 `jy_preview --close-editor`、`_try_release_project_lock` 自动切回首页）会把内存里的旧版写回磁盘。
- **现在**：草稿目录里有 `.locked`（剪映正打开）时 `JyProject(overwrite=True)` 直接报 `DraftOpenInEditorError`。确实要强制覆盖时设 `JY_ALLOW_OVERWRITE_OPEN=1`（不推荐）。
- **规程**：每次重新生成前，请用户在剪映里关闭这个草稿回到首页（或 Cmd+Q）；生成后再打开。**不要在用户可能正在看剪映时自动关闭编辑器。**

### A4 ⚠️ 「无法打开草稿：草稿内容已损坏」
- **症状**：剪映首页点开草稿直接报损坏。
- **根因**：生成到一半出错退出（这次是剪映朗读 SAMI 握手超时），留下只有模板 JSON 的半成品；或用户在 skill 写文件的过程中打开了草稿。
- **现在**：配音合成结果缓存在 `~/.cache/jianying-pro/tts/`（`JY_TTS_CACHE` 可改），合成失败整体重试 3 次；第二次生成不再联网。
- **规程**：联网的步骤（TTS、云端音乐 / 音效下载）放在写草稿**之前**做完（预热缓存）；生成过程中别让用户打开草稿。

### A5 ✅ 云端配乐 / 音效「媒体丢失」
- **根因**：`add_cloud_media` / `add_cloud_music` 下载到 `~/cloud_cache`，`add_audio_safe` 没复制进草稿；剪映 macOS 是沙盒应用，读不到草稿目录以外的文件。
- **现在**：`add_audio_safe` 和视频一样复制进 `materials/`。交付前可校验：所有素材路径都在草稿目录内。

## B. 素材 / 片段

### B1 ✅ 贴纸在剪映里不显示
- **根因**：skill 写的贴纸素材只有 `resource_id`，没有 `path`；剪映只渲染带本地资源路径的贴纸，也不会自动下载（原生草稿里 `path` 指向 `Cache/artistEffect/<id>/<md5>/`）。贴纸上挂着本机没有的动画时也整个不画（见 `jianying-11.md`）。
- **现在**：`add_sticker` 按面板索引的 md5 写入本地路径；本机没下载的贴纸打印告警并记入 `project.warnings`。
- **规程**：挑贴纸时优先本机已下载的；想用的贴纸没下载，请用户在剪映贴纸面板里点一次再重新生成。审片器（伪渲染）画不出贴纸，必须在剪映里截图核对。

### B2 ✅ 单句配音报「截取的素材时间范围超出了素材时长」
- **根因**：0.8 秒左右的短音频对齐到整帧（30fps）后，截取终点超出素材末尾不到 1 帧，底层库直接抛错。
- **现在**：不到 1 帧的超出视为取整误差，自动补齐素材时长（剪映本身也这样处理）。

### B3 ⚠️ 两个贴纸 / 两段音效同时出现报 `SegmentOverlap`
- **规程**：同一时刻并存的贴纸、音效放不同轨道（`Stickers0` / `Stickers1`、`SFX` / `SFX2`），或按时间贪心分轨。

### B4 ⚠️ 贴纸名称匹配不到
- 面板贴纸名很长且带标点（如「可爱手绘综艺体-wow，惊叹，哇哦」），`add_sticker` 按名称精确匹配；拿不准时直接传 `resource_id`。

## C. 录屏

### C1 ✅ 高清屏录屏只占左上角 / 文字糊
- **根因**：Playwright `record_video` 按 CSS 像素出画面；`deviceScaleFactor=2.5` 时只画在左上角，不开又会放大发糊。
- **现在**：`web_recorder.record_web_hidpi()` 用 DevTools 截屏流按设备像素逐帧采集（432×768 ×2.5 = 1080×1920），按时间戳合成 30fps MP4，并返回「画面就绪」时刻。

### C2 ⚠️ 移动端模拟下滚不动 / 拖动选中文字
- `isMobile=True` 时 `mouse.wheel` 不滚动；用鼠标拖动模拟滑动会选中文字（蓝色高亮）。
- 用 `web_recorder.smooth_scroll()` 改 `scrollTop`；`TOUCH_JS` 已注入 `user-select:none` 和触控圆点。

### C3 ⚠️ 录屏开头是白屏 / 加载转圈
- 每段记录「画面就绪」时刻，剪辑时 `source_start` 从这里开始截取，不要从 0 开始。

## D. 审片 / 核对

### D1 ✅ 审片对比图混进上一轮的旧帧
- **根因**：`layout_preview.py` 的输出目录不清理，采样时刻每轮不同，旧 `t*.png` 留在目录里。
- **现在**：每次运行先清掉旧帧和 `sheet.jpg`。

### D2 ⚠️ 审片通过 ≠ 剪映里正确
- 伪渲染画不出：文字背景（`TextBackground`）、贴纸、特效、转场。这些必须用 `jy_preview.py` 在剪映里截图看。

### D3 ✅ `jy_preview.py` 报 `NameError: timeout`
- 草稿不在首页列表顶部、需要滚动查找时触发。已修复。

### D4 ⚠️ `jy_preview` 截出一条细长的时间线图
- 偶发：播放器区域定位失败，截到了时间线。重新截一次；或用 `--full` 截整个窗口确认。

## E. 规程速查（每次生成都照做）

1. 联网步骤（TTS、云端素材）先做完再写草稿。
2. 生成前确认剪映没打开这个草稿（没有 `.locked`）。
3. 生成后校验：所有素材路径在草稿目录内且文件存在；草稿 ID 不是模板 ID。
4. `layout_preview.py --auto` 看版式；`jy_preview.py` 在剪映里截图看文字背景 / 贴纸 / 特效。
5. 交给用户前，自己「打开 → 关闭 → 再打开」一次，确认素材库没有「媒体丢失」。
6. 用户在剪映里打开着草稿时不要重新生成；改完先让用户关掉。
