# 钩子库：类型、好坏例子、前 3 秒画面

配合 [hook.md](hook.md)（黄金 3 秒的时间切分、结构与信息密度）使用。`prompts/hook_writer.md` 按这里的类型写 5 个不同钩子；审片器（T8）和多版本输出（`scripts/variants.py`）默认把钩子段当成必留段落。

数值是经验值，来源同 [README.md](README.md) 的调研列表；按素材调整时在剧本 `note` 里写原因。

## 通用要求

- **一句话**：口播钩子 ≤ 20 个汉字（英文 ≤ 12 词），2–3 秒读完。超过就拆成「钩子 + 点题」两段。
- **只给一个停留理由**：反差、悬念、利益、数字、提问……每个钩子只用一种，混在一起反而没有重点。
- **钩子许下的承诺必须在正片兑现**：说「3 个方法」就要讲 3 个；说「最后一个最关键」，最后一个就必须是最强的。兑现不了的钩子会被划走，还会掉完播率。
- **禁止**：「大家好，今天讲一下」「欢迎来到我的频道」「先点个关注」这类不给信息的开场；黑场、慢淡入、片头 Logo。例外：宣传片 / MV 的标题卡本身就是片名大字（见第 9 类），不算片头 Logo。
- **字幕和画面同时给**：钩子那句台词同时做成标题大字（剧本里用 `title` 元素），静音刷视频的人也能看懂。

## 前 3 秒画面要求

| 时间 | 画面 | 声音 | 剧本里怎么写 |
|---|---|---|---|
| 0–0.3s | 第一帧就有主体：人脸 / 产品 / 结果画面；不黑场、不淡入 | 开口即是钩子台词，或一个标志性音效（延迟 ≤ 0.2s） | 钩子段 `time` 从第一句台词开始；`title` 0.3s 内出现 |
| 0.3–1.5s | 证据画面亮出（结果、对比、反常识的画面），或真人近景直视镜头 | 钩子台词说完前半句 | 口播用 `camera: "push_in"`；混剪可以 2–3 个快切 |
| 1.5–3s | 标题大字落定，画面不再换主体 | 说清和观众的关系（「你也……」「如果你……」） | `title` 时长 ≥ 2.5s（场景规范下限） |
| 3–8s | 给第一个证据，或把悬念再推一步 | 进入点题 | 点题段可用 `hero` 大字 |

- **口播**：开头 3 秒真人近景或特写出镜建立信任，不加插卡（场景规范 `no_insert_first_s: 3`）。
- **带货**：第一帧就是产品或使用结果（前后对比），不是包装盒。
- **教程**：结果先行，第一帧放做完的效果，再说「3 步做出来」。
- **混剪 / 卡点**：前 3 秒 3–6 个切点，第一个强拍给最好看的镜头。
- **横屏宣传片 / MV**：标题卡钩子，0 秒片名大字压在压暗的画面上，停 3–4s 不切（第 9 类）。
- **系列教程**：0 秒集标题页或上集回顾（第 10 类），0.3s 内起旁白。
- **影视解说**：冷开场，从高潮或最反常的那 5–10 秒剪起，再回到开头。
- **没有天然钩子**：截正片里信息最密的 5–10 秒放到开头（冷开场），接 6–8 帧短叠化回到正片。

## 钩子类型

每类给出：适合场景、句式、好例子、坏例子（以及坏在哪里）、配什么画面。

### 1. 反差 / 反常识（contrast）

打破观众的预期：大家都以为 A，其实是 B。

- **适合**：口播知识、科普、测评、影视解说。
- **句式**：「你以为 X，其实 Y」「X 不是 A，是 B」「越 X 越 Y」「别再 X 了」
- **好**：「汉字其实不难记，难的是你一直在死记。」——先认同痛点，再翻转，翻转点就是正片内容。
- **好**：「每天喝 8 杯水，可能正在伤你的肾。」——反常识 + 风险，具体到「8 杯水」。
- **坏**：「今天给大家颠覆一下认知。」——只说要反差，没给反差本身。
- **坏**：「地球其实是平的。」——反差靠虚假信息，正片兑现不了，还有平台风险。
- **画面**：真人直视镜头说翻转句，或左右分屏「误区 vs 正确」，误区一侧用红色叉。

### 2. 悬念 / 信息缺口（suspense）

先给结果或一半信息，把关键留到后面。

- **适合**：剧情、影视解说、Vlog、故事型口播。
- **句式**：「直到最后我才发现……」「这个东西，99% 的人都用错了」「他做了一个决定，改变了整个公司」
- **好**：「这台旧电脑我只改了一个设置，开机从 2 分钟变成 8 秒。」——结果具体，方法留白。
- **好**：（解说）「这个男人用一张纸条，骗过了整个警局。」——人物 + 动作 + 不可思议的结果。
- **坏**：「接下来发生的事你绝对想不到。」——没有具体信息，标题党，观众已经免疫。
- **坏**：悬念在 60 秒视频的第 55 秒才揭晓，中间没有任何推进。——每 10–15 秒要给一点进展。
- **画面**：结果画面先闪 0.5–1s 再切走（「先看结果」），或定格 + 放大关键细节。

### 3. 利益 / 痛点（benefit）

直接告诉观众看完能得到什么，或戳中他正在烦的事。

- **适合**：教程、带货、干货口播、职场 / 学习类。
- **句式**：「学会这招，你能 X」「X 的人一定要看」「还在为 X 发愁？」「省下 X 元 / X 小时」
- **好**：「Excel 一个快捷键，把 2 小时的对账变成 2 分钟。」——具体工具 + 具体收益（时间对比）。
- **好**：「租房前不看这 3 个地方，押金大概率要不回来。」——痛点 + 后果 + 数量。
- **坏**：「这个方法真的很有用，建议收藏。」——没说对谁、有什么用。
- **坏**：「月入十万的秘诀。」——承诺过大、不可信，也容易违反平台规则。
- **画面**：做完后的结果画面 / 前后对比（左右或上下分屏），收益数字做成大字。

### 4. 数字 / 清单（number）

用具体数字给出确定的信息量和结构。

- **适合**：干货口播、测评、教程、旅行攻略。
- **句式**：「3 个方法……」「花了 X 天 / X 元，总结出……」「第 X 个最关键」「X 秒教会你」
- **好**：「去了 12 次日本，这 3 家便利店的东西我每次都买。」——数字给可信度（12 次）+ 数字给结构（3 家）。
- **好**：「30 秒学会扎一个不会散的丸子头。」——时长承诺和视频长度一致。
- **坏**：「分享一些小技巧。」——没有数字，观众不知道要看多久、值不值。
- **坏**：「100 个必备 App。」——数字大到 60 秒讲不完，承诺落空。
- **画面**：数字大字放在标题带（`title`），每讲一点出一个序号标注（`label`）。

### 5. 提问 / 代入（question）

问一个观众会在心里回答的问题，让他代入。

- **适合**：口播知识、情感、教育、外语学习。
- **句式**：「你有没有发现……」「为什么 X 总是 Y？」「如果 X，你会怎么做？」
- **好**：「为什么你背了 3000 个单词，还是听不懂美剧？」——问题具体、观众大概率经历过、有答案。
- **好**：「你知道『人』字最早长什么样吗？」——好奇心问题 + 正片马上给答案。
- **坏**：「你们觉得呢？」——放在开头没有上下文，观众没法回答。
- **坏**：「你想变得更好吗？」——谁都会答「想」，没有信息量。
- **画面**：真人直视镜头提问，问完停 0.3–0.5s（留思考时间），标题大字只放问题本身。

### 6. 结果先行 / 展示（result）

先给最终效果，再讲怎么做到的。

- **适合**：教程、带货、改造类 Vlog、卡点混剪。
- **句式**：「这是我用 X 做出来的」「改造前 / 改造后」「先看效果」
- **好**：（教程）第一帧就是做好的动效，台词「这个效果只用 3 步」。
- **坏**：前 10 秒在讲软件怎么安装，效果最后才出现。
- **画面**：成品画面 + 轻推（1.0→1.08）；前后对比用硬切或擦除转场。

### 7. 场景 / 身份（scene）

点名一个具体场景或人群，让对号入座的人留下。

- **适合**：Vlog、带货、职场、地域内容。
- **句式**：「上班族的午饭……」「第一次去 X 的人……」「家里有 X 的注意了」
- **好**：「家里有 3 岁以下宝宝的，这个插座一定要换。」——人群 + 具体物件 + 风险。
- **坏**：「所有人都应该看看。」——没有点名任何人，等于没点。
- **画面**：一眼能认出的场景画面（工位、厨房、机场），人群关键词做成大字。

### 8. 冲突 / 争议（conflict）

摆出两种对立观点或一个矛盾。注意争议要基于事实，不拉踩具体个人和群体。

- **适合**：测评、观点口播、影视解说。
- **句式**：「A 说 X，B 说 Y，到底谁对？」「花 3000 和花 300 的，差在哪？」
- **好**：「300 的耳机和 3000 的耳机，盲听你能分出来吗？」——对立具体、观众想知道答案、可以用实验兑现。
- **坏**：「X 品牌就是垃圾。」——情绪化拉踩，没有可兑现的信息。
- **画面**：左右分屏两个对象，中间「VS」或问号。

### 9. 标题卡（title_card）

0 秒直接给片名大字，停 3–4s 不切，靠片名、slogan 和画面质感留人。见 [hook.md](hook.md)「标题卡钩子」。

- **适合**：横屏宣传片、MV、教程 / 演示录屏的开头。竖屏短视频少用（首帧 0.3–0.8s 就要有变化）。
- **句式**：「片名 / 英文名 / 一句 slogan」「第 N 集 · 主题」「使用 X 做 Y」
- **好**：（游戏宣传片）主标题「星火突围」+ 英文名 + 「动作肉鸽 · 一局就停不下来」，压在压暗的实机画面上，HUD 还在动，0.06s 起音乐。——片名 + 品类 + 爽点，一屏讲清是什么。
- **好**：（产品演示）「一句话生成周报」压在产品界面上，2.5s 后切到操作。——标题就是结果承诺。
- **坏**：纯 Logo 动画 5 秒，没有一句说明。——不知道这是什么、和我有什么关系。
- **坏**：标题卡停 8 秒还没进正片。——超过 4s 就是拖。
- **画面**：压暗（亮度约 0.3）的实机 / 乐队全景 / 产品界面，有轻微动态；大字 0.2–0.3s 叠化进入；音乐 0.3s 内进来。剧本里用 `hero` 元素（`text` + `sub`），场景段落「标题卡」/「片名」默认整段一个镜头。

### 10. 上集回顾 / 本集标题（recap）

系列内容从第 2 集起，用上一集的成果或本集标题页开场，让追更的人马上接上。

- **适合**：系列教程、Workshop、连续剧情 / 连载 Vlog。
- **句式**：「上一集我们做出了 X，这一集让它 Y」「第 N 集 · 主题」「上集留下的问题：X」
- **好**：「上一集的助手只会回答，这一集让它自己动手。」——回顾 + 本集变化，一句话。
- **好**：集标题页「第 5 集 · 接入数据」+ 流程条标出本集位置，0.3s 起旁白。——观众知道看到哪了。
- **坏**：「大家好，欢迎回到我们的系列，上一集我们讲了很多内容……」——寒暄 + 没有具体信息。
- **坏**：回顾上一集讲了 30 秒。——回顾只说和本集有关的一点，3–5s 讲完。
- **画面**：上集成果画面（1–2 个镜头）或集标题页，标题用 `title` 元素，停 3–4s。

## 怎么选

| 场景 | 首选 | 备选 | 少用 |
|---|---|---|---|
| 口播知识 | 反差、提问 | 数字、利益 | 场景 |
| 教程录屏 | 结果先行、利益 | 数字 | 悬念 |
| 带货种草 | 利益、结果先行 | 场景、冲突 | 提问 |
| 影视解说 | 悬念、冲突 | 反差 | 数字 |
| Vlog | 场景、悬念 | 结果先行 | 冲突 |
| 卡点混剪 | 结果先行（最强镜头先出） | 反差（画面对比） | 文字型钩子 |
| 剧情短片 | 悬念（冷开场） | 冲突 | 利益 |
| 宣传片（横屏） | 标题卡 | 结果先行（最强实机先闪一下） | 提问 |
| 音乐视频（MV） | 标题卡（片名） | 场景 | 文字型口播钩子 |
| 系列教程 | 上集回顾 / 本集标题、结果先行 | 利益 | 悬念 |

## 钩子自检

写完每个钩子过一遍，有一条不满足就改：

1. 去掉这句话，观众会少知道什么？答不上来 = 没有信息量。
2. 有没有具体名词或数字（不是「一些」「很多」「某个」）？
3. 正片能不能兑现？在哪一段兑现（写出段落 id）？
4. 2–3 秒能说完吗？口播 ≤ 20 字。
5. 第一帧画面是什么？能不能静音看懂？
6. 有没有夸大、虚假、拉踩、绝对化用语（「最」「第一」「100%」在广告类内容里要慎用）？

## 金句（结尾 / 总结用）

金句是总结段的一句话收束，让人想截图、转发或评论。

- **短**：≤ 15 字，能做成一行大字。
- **对仗 / 对比**：「记字先看图，看图先看人。」「不是你不努力，是方法错了。」
- **回扣钩子**：钩子问的问题，金句给出答案；钩子的反差，金句再说一遍结论。
- **可截图**：脱离上下文也成立。
- **坏**：「希望对大家有帮助。」「以上就是今天的内容。」——没有内容。
- 剧本里放在总结段，用 `title` 或 `keyword` 元素，段落 `camera: "punch_in"` 强调推近（见场景规范「总结」段）。
