# 插卡 / B-roll / 信息卡

## 什么时候放

- 说到对应关键词时出现（与台词严格对应），顺序是「对象 → 关系 → 结论」。（wenb、douyin-h3）
- 同一时刻只放**一个**主信息视觉。（douyin-h3）
- 插卡必须带标注，说明它是什么，否则观众不知所云。（国风规范）
- B-roll 的用法是：原声保留，画面替换成与台词匹配的素材。（维基·B-roll、maxazure）
- 教学、口型段落（例如跟读发音）不加插卡，让观众看脸。（国风规范）

## 时长

- 插卡 6–8s：短于 3s 看不清，长于 10s 会盖住人脸太久。（国风规范）
- 一组信息卡至少 10s，同时最多 5–7 个节点。（wenb）
- 入场 0.27–0.47s，大标题 0.33–0.53s；入场后普通元素至少停 0.9s，结论至少停 1.2s。（wenb）

## 放在哪：人脸避让

先看 `analysis.json` 的 `faces`：

| 情况 | 做法 |
|---|---|
| `card_zones` 有「头顶上方」 | 插卡中心放在该区间，宽度不超过画面 86% |
| `card_zones` 有「下巴与字幕之间」 | 小尺寸插卡放这里（scale 0.4–0.6），标注放插卡上方 |
| `card_zones` 为空（近景自拍，人脸占满画面） | 三选一，**问用户**：① 整屏切到图片、人声继续（B-roll 式，图片放满画面并加缓推 1.0→1.08）；② 真人缩成小窗（scale 0.35–0.45，放到角落），图片放大到主区域；③ 只在说完一句后的间隙短暂压屏 ≤ 3s |

- 横版素材放进竖屏只能做插卡；宽度占比太小（< 60%）时改成整屏 B-roll，加背景虚化垫底。（国风规范）
- 静止图片加 1–3% 的轻推，或 1.0→1.08（Ken Burns），避免死板。（douyin-h3、cutcli）
- 插卡加投影（alpha 55、blur 28），和背景分开。
- 红色只用于错误或否定。（wenb、maple）
- **标注要和背景有对比**：金箔、墨色这类深色花字放在亮天空或模糊背景上会看不清（2026-10-22 V5 剪映截图实测）。亮背景上的标注用白字 + 黑描边；深色花字只放在深色背景前（比如衣服、深色插卡上）。
