# 调色

来源：知乎《剪映从入门到精通：全民视频剪辑实用手册》第 4.4、6.3 节（下称「手册」）。装配器写法：分镜 `main.grade` = `{"adjust": {...}, "filter": {"name", "intensity"}}`，风格默认值见 `styles/*.json` 的 `grade`。

## 原则

- 核心是**统一色调 + 突出主体**。同一视频的所有片段用同一个滤镜，保证整体性。
- 滤镜强度不要拉满。

## 基础调节顺序和默认值

按 亮度 → 对比度 → 饱和度 → 锐化 → 高光 → 阴影 → 色温 → 色调 的顺序调整。

| 参数 | 默认调整 | 说明 |
|---|---|---|
| 亮度 | 暗画面 +10 ~ +20；亮画面 -10 ~ -15 | |
| 对比度 | 日常 +10 ~ +20；复古 -5 ~ -10 | |
| 饱和度 | 日常 +5 ~ +10；复古 -10 ~ -20 | 防止失真 |
| 锐化 | +10 ~ +20 | 所有视频都适用 |
| 高光 | -10 ~ -20 | 防止亮部过曝丢细节 |
| 阴影 | +10 ~ +20 | 提亮暗部、保留细节 |
| 色温 | 暖调 +5 ~ +10；冷调 -5 ~ -10 | |
| 色调 | 偏红 +5 ~ +10；偏青 -5 ~ -10 | |

注意：手册里的数值是剪映面板上的数字，`set_adjust` 也用面板数值，可以直接填。

## 滤镜强度（按题材）

| 题材 | 滤镜类型 | 强度 |
|---|---|---|
| 日常 vlog | 清新类 | 50–60% |
| 风景 | 电影感类（青橙 / 黑金） | 60–70% |
| 人像 | 人像类 | 40–50% |
| 复古 | 复古类（港风 / 胶片） | 50–60% |
| LUT | 导入的 .cube | 50–70%（`set_lut` 的 strength） |

## 常用配方

- **电影感青橙**（风景 / 城市 / 人像）：
  - 调节：亮度 +10、对比度 +15、饱和度 +10、锐化 +20、高光 -15、阴影 +15、色温 -10、色调 +5；
  - HSL：红色饱和度 +15、亮度 +15；蓝色饱和度 +20、亮度 -10；
  - 滤镜：「青橙」60%；
  - 暗角：+20。
- **HSL 提亮肤色**：红色饱和度 +10 ~ +20、亮度 +10 ~ +20。
- **HSL 天空更蓝**：蓝色饱和度 +20 ~ +30、亮度 -5 ~ -10。
- **色轮**：阴影偏蓝 = 冷调氛围；中间调偏红 = 提亮肤色；高光偏黄 = 暖调风景（`set_color_wheels`）。
- **局部调色**：主视频用暗调滤镜，复制一层加圆形蒙版框住主体、用亮调滤镜、透明度 70%。对应 `add_local_adjust`。
- **按情绪分场景调色**（剧情类）：
  - 青春 / 回忆：暖，色温 +10；
  - 伤感：冷，色温 -10、饱和度 -10；
  - 温暖重逢：对比度 +15，用电影感滤镜。
