# 版面组织（插卡页 / 点题页 / 结束卡）

2026-10-23 V7 复盘：文字压圆形、圆形左右被截平、浅底黑字看不清，根源都是「手调单个元素坐标 + 估算字宽」。现在的做法：

## 1. 先切网格，再放元素

- 每个画幅在 `formats/<id>.json` 的 `circle_layout.regions` 里定义**互不重叠**的区域：`media`（图片 / 点题字）、`label`（标注 / 互动引导，紧贴圆形右侧）、`subtitle`（字幕带，贴安全区下沿）、`end_tag` / `end_title` / `end_words`（结束卡）。圆形讲解人由 `speaker` 决定，占自己的一块。
- 区域之间留 `gutter`；元素只能放进区域，不能单独写坐标。要改版式就改区域，对所有项目生效。
- 一页只有一个视觉焦点（图片或点题字），层级不超过三级：焦点 > 标注 > 字幕。

## 2. 用真实字体量字宽

- `scripts/utils/text_metrics.py` 读剪映缓存里的字体文件量宽（size 1 ≈ 6.4 画布像素，截图校准）。
- 放不下时先缩到 88% 试一行，再折成两行（两行尽量等长，在标点 / 空格 /「·」/ 开括号前断，不在括号里断），再不行按 4% 一档缩字号，最小 70%；仍放不下编译器报警告。
- 换行由编译器写进文字内容：剪映的「最大行宽」对英文常常不折行。

## 3. 圆形蒙版不能超出素材

蒙版直径 ≤ 素材短边的 94%，圆心离素材边至少一个半径，否则超出的部分没有画面，圆的左右会被截平。

## 4. 浅底上的字

- 实心墨色 #1A1A1A 或朱红，不加花字、不加描边（`add_text_simple` 默认加黑描边，卡片角色要写 `"border": false`）。
- 枯笔书法字（挥墨体）只用于 ≥ 12 号、≤ 8 字的短标签；含英文 / 拼音的标注不用行楷（拉丁字母笔画太细），用粗宋。

## 5. 审片器对应检查

`[重叠]` 文字压到圆形讲解人 / 插卡（重叠超过文字面积的 15%）；`[蒙版]` 蒙版超出素材；`[对比度]` 字色（和描边）对背景 < 3:1；`[字体]` 枯笔字体字号过小。

## 6. 剪映会覆盖草稿

草稿在剪映里打开时重新生成，关闭编辑器时剪映会把内存里的旧版本写回去。重新生成前先关掉编辑器（`jy_preview.in_editor()` 为 False）。
