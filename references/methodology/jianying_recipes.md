# 剪映配方（效果 → 操作 → skill 写法）

来源：《剪映视频剪辑从小白到大师（电脑版）》（龙飞编著，2021 年版，68 个案例）。书里的面板名称是早期版本的写法，**下面都已换成剪映 11.x 的名称**（2026-10-23 按本机面板索引核对过）：罗马数字前面要加空格，比如「星火 II」「打字机 II」。「春光乍泄」「雾山」「月升王国」三个滤镜已经下架，表格里给了替代品。

skill 写法：
- `grade` / `overlays` / `texts` / `effects` / `camera` 是分镜表字段（见 `storyboard_schema.md`）；
- 其余是 `JyProject` 的 API：`add_video_animation`、`set_blend_mode`、`set_curve_speed`、`add_mask_simple`、`set_background_fill`。

## 调色

| 配方 | 参数 | skill |
|---|---|---|
| 风光通透 | 亮度 5、对比度 15、饱和度 26、锐化 15、色温 -8、色调 -5 | `grade.adjust` |
| 青橙 | 滤镜「即刻春光」或「青橙」100，加上 亮度 -6、对比度 5、饱和度 9、锐化 10、高光 80、色温 8、色调 -5 | `grade` |
| 黑金夜景 | 滤镜「黑金」85 | `grade.filter` |
| 赛博朋克 | 滤镜「赛博朋克」100 | `grade.filter` |
| 清新带货 / 美食 | 滤镜「鲜亮」66 | `grade.filter` |
| 秋天氛围 | 暖色调节 + 特效「落叶」铺满全片（原书的「月升王国」滤镜已下架，改用暖色调节） | `grade` + `effects` |
| 调色前后对比 | 同一素材在 5s 处分割，后一段加滤镜，接缝用「向右擦除」并拉到最长（片段级滤镜，不用像书里那样先导出再导入） | 分成两个 `keep` 段 + 转场 |
| 竖屏上下对比 | 主轨放调色版、画中画放原片，各占半屏，画中画音量 0，上下各加一行说明文字 | `overlays` + `texts` |

## 转场与变速

| 配方 | 参数 | skill |
|---|---|---|
| 无缝加速转场 | 每段用曲线变速：前两个、后两个控制点 6.0x，中段 1.0x | `set_curve_speed` 自定义（待补：分镜字段） |
| 叠化瞬移 | 0.5x 慢放，剪掉中间一段，接缝放「叠化」并拉到最长，最后接空镜 | `keep` + 转场 |
| 大片感 | 曲线变速「蒙太奇」「英雄时刻」「子弹时间」+ 转场「拉远 / 推近」+ 特效「电影感」 | `set_curve_speed` + 转场 + `effects` |
| 硬切穿越 | 同机位两段在起跳点硬切（扔衣服变人、穿铁门）。切点需要人工找 | `keep` |
| 甩入转场 | 视频动画入场「向右甩入」「向左上甩入」，0.3–0.5s | `add_video_animation` |
| 主体切换 | 转场「圆形遮罩」「漩涡」「回忆 II」（VIP） | 转场 |
| 片头片尾 | 首段特效「开幕」，尾段「闭幕」，边框特效「录制边框 II」 | `effects` |

## 卡点

节拍点需要另外检测（见「待补能力」），检测好后，每个效果的时长等于节拍间隔。

| 配方 | 参数 |
|---|---|
| 多屏卡点 | 节拍区间依次放分屏特效「两屏 → 三屏 → 四屏 → 六屏 → 九屏 → 九屏跑马灯」 |
| 拍照卡点 | 片段入场「向下甩入」1.0s，入场动画结束点放音效「拍照声」，边框特效「录像带」（原书的「录像机」已下架） |
| 卡点开头 | 第一段叠特效「变清晰」，时长等于第一段；之后各段叠「星火炸开」或「星火 II」 |
| 闪白卡点 | 每个鼓点放特效「闪白」0.1s；或者 `punch_in` |
| 矩形蒙版灯光秀 | 主轨用滤镜「牛皮纸」做底；原片放画中画按节拍分割，每段一个矩形蒙版露出一块；倒数第二段用圆形；最后一段加「闪动」+「魅力光束」 |
| 蒙版逐拍显现 | 底片不透明度 0；各节拍在不同轨道依次叠爱心 / 星形蒙版（羽化 10）；最后一段蒙版放大到全屏 + 组合动画「形变缩小」；特效「星河」 |
| 旋转立方体 | 9:16 + 背景模糊（应用到全部）；镜面蒙版旋转、羽化拉满；组合动画「立方体」；特效「霓虹灯」 |

## 合成

| 配方 | 参数 | skill |
|---|---|---|
| 粒子 / 烟雾 / 光效叠加 | 素材放画中画，混合模式「滤色」（去掉暗部、保留亮部，适合黑底素材） | `set_blend_mode(seg, "滤色")` |
| 乌鸦、星空等暗色素材叠加 | 混合模式「正片叠底」（保留暗部，适合白底或亮底素材） | `set_blend_mode` |
| 飘雪 | 飘雪素材用「变亮」+ 音效「风声」+ 场景之间「闪黑」转场 | `set_blend_mode` + `sfx` |
| 挥手换天 | 天空素材画中画 + 线性蒙版（羽化 30）+「正片叠底」；挥手动作之后主轨亮度 -20；特效「星星闪烁 II」 | 蒙版 + 混合模式 + `adjust` |
| 镜面分身 / 三屏开场 | 同机位两段（或三层画中画），镜面蒙版宽约画面 1/3、旋转 20°、羽化 10；入场「向左上甩入」 | `add_mask_simple("镜面")` |
| 定格分身 | 在每个姿势处定格，定格段移到画中画并延到片尾，加镜面蒙版羽化 15；9:16 + 模糊背景 | 定格 + 蒙版 |
| 空中定格 | 扔伞处定格；原片放画中画，线性蒙版只露出人物那一侧 | 定格 + 蒙版 |
| 轻功残影 | 同一素材叠 3 层，起点依次延后 0.5s，三层都 3.0x，上两层不透明度 50% | `overlays` |
| 镜像双人 / 逆世界 | 复制一层到画中画，水平镜像（双人）或旋转 180° + 镜像（上下对称） | `flip`（待补：分镜字段） |

## 文字

| 配方 | 参数 |
|---|---|
| 口播字幕动画 | 入场「打字机 II」拉满；重点句用循环「逐字放大」；入场 + 出场的总时长不能超过文字时长 |
| 卡拉 OK 歌词 | 歌词字幕 + 入场「卡拉OK」，动画时长等于这一句的时长 |
| 粒子消散字 | 花字，入场「放大」、出场「打字机 II」；粒子视频放画中画，混合模式「滤色」 |
| 古风烟雾字 | 竖排文字（待补）+ 花字 + 入场「打字机 II」+ 出场「渐隐」，分 3 段错开；每段上面盖一层烟雾素材，混合模式「滤色」 |
| 主题标题 | 花字，入场「放大」6s + 出场「闭幕」6s；首 / 中 / 尾依次放「烟花 / 星星冲屏 / 星光绽放」 |
| 片头标题 | 花字 + 入场「生长」拉满；说明文字入场「向上滑动」 |
| 贴纸组合 | 入场「向下滑动」、循环「闪烁」、出场「缩小」 |

| 幸福恋人 | 光效视频放画中画，混合模式「滤色」；组合动画「悠悠球」或「碎块滑动 II」；特效「飘落闪粉」或「爱心缤纷」 |

## 音频

- 加 BGM 时关掉原声，把结尾多出的部分剪掉；BGM 淡入 3.5s、淡出 1.8s。书中把 BGM 音量调到 200%，偏响，**以响度统一为准**，见 `audio.md`。
- 用音乐的高潮段：把左端拖到高潮开始处，再把整段移到 0s。
- 视频文件可以直接当音频源用：把视频导入音频轨，原视频音量设 0。

## 界面与导出

- 抖音竖屏用 9:16、1080×1920；分辨率过大，会被平台压缩变糊。
- 导出：mp4，码率选「高」；**帧率和拍摄帧率保持一致**，卡点和慢动作用 60fps。
- 主轨不能直接改成画中画，主轨上至少要留一段视频。
- 滤镜轨和调节轨会作用于它下面所有轨道；skill 用片段级的滤镜和调节，没有这个问题。
- 入场 + 出场动画的总时长不能超过片段时长；循环动画调快慢就行，不用设时长。
- 转场选中后可以「应用到全部」。

## 待补能力（来自这本书，按用到的频率排序）

1. **节拍检测**：卡点类案例都要用。计划用 ffmpeg 或 librosa 检测节拍，给卡点场景输出时间点。
2. **分镜字段补齐**：画面镜像（`flip`）、视频入场 / 出场 / 组合动画、自定义曲线变速。这些在 API 里已经有，分镜表还不能直接写。
3. **竖排文字**。
4. **倒放**：先用 ffmpeg 生成倒放素材再导入。
