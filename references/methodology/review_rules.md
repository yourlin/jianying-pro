# 可自动检查的规则

来源：`edit_grammar.md`、`staging.md`、`shot_grammar.md`，这三份规则提炼自《剪辑的语法》《电影语言的语法》《镜头的语法》。

| 状态 | 含义 |
|---|---|
| ✅ | 已经在审片器 `layout_preview.py` 里实现 |
| 🔧 | 在编译器或装配器里自动保证 |
| ⏳ | 计划实现，需要的分镜字段或数据还没有 |

数值标【建】的，是按书中原则推导出来的，要用实际成片校准。

## 时间线

| 规则 | 状态 |
|---|---|
| 覆盖层或文字短于 0.4s，等于没出现（闪帧） | ✅ |
| 氛围特效短于 3s | ✅ |
| 片段超出成片时长 | ✅ |
| 覆盖层视频没有静音 | ✅ |
| **第 0 帧必须有画面** | ✅ |
| **小跳**：同一素材相邻片段，剪点前后缩放差在 1.03–1.15x 之间。要么不变（明确的跳切），要么差 ≥ 1.25x【建】 | ✅ |
| 叠化 0.3–2.5s（默认 1s）；擦除 ≤ 0.8s | ✅ |
| 非硬切转场总数 ≤ max(5, 每分钟 2 个)【建】 | ✅ |
| 标题、标注、CTA 停留 ≥ max(2s, 阅读单位 × 0.4s)，上限 10s；汉字按字算，英文按词算【建】 | ✅ |
| 剪气口后用假景别遮剪点（缩放 1.25x 拉回） | 🔧 编译器 |
| 字幕不超过下一句开始；碎条（少于 4 字或短于 0.55s）合并 | 🔧 装配器 |
| 字幕底边贴着安全区下沿 | 🔧 编译器 |
| 1080p 素材放大不超过 1.3x、4K 不超过 2x | ⏳ 需要素材分辨率和缩放关键帧 |
| push_in 缩放速度 ≤ 5%/s（punch_in 除外）；运动镜头首尾静止 ≥ 0.3s | ⏳ |
| pull_out 只放在段落最后一镜 | ⏳ 需要段落边界 |
| 相邻两个 pan 方向相反 | ⏳ |
| 插入 / B-roll / 反应镜头：口播 ≥ 1.5s，剧情 ≥ 2s，≤ 6s | ⏳ 需要镜头角色 |
| 平行剪辑段落，镜头时长逐个递减 | ⏳ 需要 `cross_cut` 标记 |
| J/L cut 音画错开 0.1–1.0s，> 1.5s 算音画错位 | ⏳ 需要分离音频轨 |
| 片尾配乐结束点距成片结尾 ≤ 0.5s，或最后 0.5–2s 淡出 | ⏳ |
| 人声段配乐至少低 12dB | ⏳ 需要电平测量（现在用音量 0.2 近似） |

## 机位与连贯（需要剧本字段，都是 ⏳）

计划新增的剧本 / 分镜字段：`shot_size`（景别）、`axis_side`（轴线侧）、`screen_side`（画面左右）、`move_dir`（运动方向）、`gaze`（视线）、`role`（镜头角色：主镜头 / 插入 / 反应 / B-roll）、`scene_id`。

1. 同一场景里 `axis_side` 一致；相邻镜头人物左右不能互换。需要越轴时，中间要有切出、中性或转头镜头。
2. 两个对视的单人镜头，视线方向相反。
3. 场景第一个镜头是远景类，除非标了 `creative_open`。
4. 连续 4 个以上近景之后，要有一个中景或更宽的镜头（竖屏口播放宽到 6 个）。
5. 同一视轴上跨 3 级以上景别，中间没有中景，给出警告。
6. 三人场景里，双人镜头不要接双人镜头。
7. 同一场景内只用硬切，除非标了 `flashback` / `montage` / `time_skip`；对话正反打之间不用叠化。
8. 对话超过 30s，至少再交代一次全景或双人镜头。
9. 相邻片段平均亮度差 > 35%（又没标有意为之），给出调色匹配警告；画面清晰度低，给出虚焦警告。
10. 竖屏人像：双眼在距顶部 30%–38% 处，下巴不出画。需要逐帧检测人脸，`analyze_footage.py` 已经有人脸位置。
