# 开头钩子与结构

## 黄金 3 秒（所有场景）

| 时间 | 要做到什么 | 来源 |
|---|---|---|
| 0–0.3s | 第一个有意义的字 / 画面出现，不要黑场、不要慢慢淡入 | douyin-h3 |
| 0–1.5s | 拦住划走：证据画面 0.3–0.8s 内亮出，或抛出问题 / 反差 | douyin-h3 |
| 1.5–3s | 讲清「和观众有什么关系」，3 秒内交代主题 | douyin-h3、TikTok |
| 3–8s | 给证据或留悬念；第 8 秒还在铺垫话题就要重剪 | douyin-h3、TikTok（前 6 秒放钩子） |

- 只用**一个**停留理由：证据 / 痛点 / 反差 / 风险 / 转变，五选一。（douyin-h3、recap）
- 禁止「大家好，今天讲一下」式开场；开头的承诺必须在正片兑现。（douyin-h3）
- 没有天然钩子时：截取正片里 5–10 秒信息最密的一段放到开头做**冷开场**，再接正片，用 6–8 帧短叠化。（maple）
- 口播类开头用近景或特写，真人先出镜建立信任，**开头 3 秒不加插卡**。（coach、国风规范）

## 结构与信息密度

- 每个保留片段都要带来一次变化（信息、情绪或局势）。入点尽量晚、出点尽量早，但不能丢前提。（recap）
- 信息按「对象 → 关系 → 结论」顺序出现，结论不能先于前提。（wenb）
- 结尾放行动号召（CTA）：评论区提问 / 关注 / 下期预告。CTA 卡至少停留 3 秒；综艺访谈类的关注引导条可以停 8 秒。（wrapper）
- 长视频转短视频的选段：用 30 秒滑动窗口打分，强调词 +2、问句 +1、数字 +1、音量峰值 +2，取最高的 3 段。（capcut-skill）

## 国内经验

来源：databrush《黄金3秒开头怎么剪》、echohives《短视频脚本写作公式》。

- 时间切分：
  - 0–0.5s：启动帧 + 一个标志性音效，音效延迟 ≤ 0.2s。
  - 0.5–2s：抛出信息缺口。
  - 2–3s：承诺「继续看能得到什么」。
  - 结尾 2–3s：放 CTA。
- 镜头密度：首帧停留 0.3–0.8s；混剪类前 3 秒有 3–6 个切点，口播可以少一些。
- 每 3–5 秒一个信息点。一条视频只解决一个核心问题，多个卖点拆成多条。
- 钩子五类：场景型、问题型、结果先行、反常识、直接利益。
- 口播 60s 的另一种结构：钩子 0–5s（8%）→ 误区（17%）→ 3 个干货点（50%）→ 总结（17%）→ CTA（8%）。
