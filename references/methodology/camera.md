# 运镜

## 后期运镜（装配器 `main.camera`）

拍摄时没有运镜，可以用关键帧补。以下是默认值（经验值），对应装配器的 `move`：

| 运镜 | 情绪 / 用途 | 剪映关键帧（装配器 move） |
|---|---|---|
| 缓推 | 紧张、亲密，引导看人物内心；讲到重点时 | `push_in`：3s 内 1.00 → 1.10，缓动 |
| 强调推近 | 金句、重音、反转 | `punch_in`：0.15s 推到 1.15–1.20，句末回到 1.0 |
| 缓拉 | 交代环境、抽离、收尾 | `pull_out`：3–4s 内 1.20 → 1.00 |
| 摇 | 揭示新信息、跟随动作（Ken Burns 平移） | `pan_left` / `pan_right`：先放大 1.15，3–5s 内横移 |
| 升降 | 规模、宏大或压迫 | `tilt_up` / `tilt_down`：4s 内纵移，叠加 5% 缩放 |
| 震动 | 冲击、惊讶，配音效 | `shake`：0.3–0.5s |
| 甩镜转场 | 时间流逝、紧张节奏 | 用剪映「甩入 / 向左甩入」等转场，每侧 0.2–0.3s |
| 快速变焦 | 不安、刻意的人工感 | `punch_in` amount 0.30，0.3s |

- 1080P 素材放大不超过 120%，4K 不超过 150%，否则会糊。（CapCut 帮助、经验值）
- 放大时适当上移，保持头顶留白一致。（维基·Headroom）
- 运镜要有理由：一句话里最多一次，相邻两次运镜间隔 ≥ 3s；口播类全片 4–8 处够了（经验值）。
- 同机位跳剪时，用 100% ↔ 115% 交替缩放做「假景别」（见 [pacing.md](pacing.md)）。

## 拍摄时的运镜（给用户的拍摄建议）

| 运镜 | 怎么拍 | 来源 |
|---|---|---|
| 推 / 拉 | 稳定器慢慢靠近 / 后退，或从特写退到全景 | StudioBinder |
| 摇 | 以脚为轴转动身体 | StudioBinder |
| 移 / 跟 | 和人物保持固定距离，平移或跟随 | StudioBinder |
| 升降 | 手持从低处举到高处 | StudioBinder |
| 环绕 | 以人物为圆心绕行（后期很难模拟，只能用 ±3° 旋转加缩放近似） | StudioBinder |
| 甩 | 前一镜头结尾快速甩出，后一镜头开头沿同方向甩入 | 维基·Whip pan |

## 剪映手册的关键帧和变速

来源：知乎《剪映从入门到精通》第 4.3、4.6 节。

- 关键帧间隔 0.3–0.5s 动画更流畅；用缓入 / 缓出曲线，避免生硬（装配器默认就是「缓动」）。
- 模拟运镜：开头记原大小，1s 处缩小并右移，2s 处放大并左移，就是推拉摇移。
- 动态跟踪：每 0.5s 调一次贴纸位置，让它跟着人物移动。
- 参数渐变：滤镜强度用关键帧从 100% 渐变到 0%，做画面过渡。
- 变速参考：
  - 0.5x 慢放，突出细节或氛围；
  - 2x / 4x 快放，压缩过程；
  - 10x 极快放，表现时间流逝。
- 慢动作素材最好用 60fps 拍摄。
- 定格：精彩瞬间（跳跃最高点、成品）定格约 1s，再配文字。
