# 音频

| 项目 | 数值 | 来源 |
|---|---|---|
| 人声 | -12 到 -6 dB；先降噪，再做人声美化（可选） | coach |
| BGM（口播 / 知识类） | -24 到 -18 dB，音量系数约 0.18–0.25 | coach、recap、cutcli、国风规范 |
| BGM（Vlog） | 约 0.55；有人声段落压到 0.25 以下 | cutcli |
| BGM（卡点 / 无人声） | 0.8–1.0 | 经验值 |
| 音效 | -18 到 -12 dB，约 0.3–0.5 | coach |
| 成片响度 | -14 LUFS，真峰值 ≤ -1 dBTP（装配器 `main.audio.loudness_lufs`） | coach、promo、recap |
| BGM 淡入 / 淡出 | 1.2s / 2.5s | 国风规范 |

- 覆盖层视频一律静音（`mute: true`），否则会和旁白、BGM 打架。（国风规范）
- 音乐情绪跟着叙事走：讲痛点时用稀疏、没有鼓的段落，转折处进入爆发。（promo）
- 解说、影视二创：每个片段先定好由谁主导声音（原声 / 动作声 / 沉默 / 旁白），旁白只在必要时出现。（recap）
- 配乐 skill 只能按名称和分类挑，听不了，所以要让用户在剪映里试听。

## 国内经验

来源：diantuoyi《剪映口播音乐剪辑指南》、aimusic-tools《旅行 Vlog 配乐时间轴》。

- 口播 BGM 压到 -12 到 -18 dB；人声峰值 ≤ -6 dB，音乐峰值 ≤ -12 dB。
- 金句处音乐再降 5 dB；金句前 0.5s 可以把音乐压到几乎静音，做「留白」。
- BGM 首尾各淡入淡出 0.5–1s。
- Vlog 旁白段音乐下压 8–10 dB；静音段开始前 1–2s 淡出。
- 音乐情绪的变化要比画面切换提前 0.5–1s。

## 剪映手册的「黄金比例」

来源：知乎《剪映从入门到精通》第 2.4、3.2 节。

| 轨道 | 剪映音量 | 换算成装配器的 volume |
|---|---|---|
| 视频原声 | 50–80%（没有原声就调成 0） | 0.5–0.8 |
| 背景音乐 | 20–30% | 0.2–0.3 |
| 音效 | 10–20% | 0.1–0.2 |
| 录音 / 口播 | 70–90% | 0.7–0.9 |

- 口播：人声和背景音乐约 8 : 2。
- 所有音频都加淡入淡出，默认 1 秒。
- 录音距离麦克风 10–20cm；降噪默认强度即可。
- 不要用热门歌曲的高潮段，容易和别人撞车。
- 变速后音频容易失真：先分离音频再单独变速，或者直接重新配乐。
