# 机位与调度：轴线、对话、动作衔接、单机位模拟多机位

来源：《电影语言的语法》（阿里洪，全书 30 章）、《剪辑的语法》《镜头的语法》。只提炼规则，没有复制原文。

## 体系

- **动作—反动作**：每条信息由「发生了什么 + 谁对它有反应」两部分组成，所以剪辑的根本是平行地交替呈现两个注意中心。
- **三个匹配**：切镜时，人物在画面里的位置（左 / 中 / 右区）、运动方向、视线方向，三者都要接上。
- **三角形机位**：在两人头部之间画一条关系线，摄影机只放在线的一侧。
  - 三角形顶点：拍全景，交代空间。
  - 底边两点：拍外反拍（过肩）、内反拍（单人）、平行、直角或共同视轴镜头。

## 轴线（180° 规则）

- 同一场戏里，所有镜头的轴线侧都一致；相邻镜头里人物的左右位置不能互换；两个对视的单人镜头，视线方向必须相反。
- **合法越轴的四种办法**：
  1. 插一个切出镜头（0.8–1.5s 的空镜或反应镜头）；
  2. 插一个中性方向镜头（人或车正对、背对镜头运动）；
  3. 人物转头、转身，把方向带过去；
  4. 前景人物下蹲或起身，借这个动作掩护换边。
- **银幕方向**：人物从左边出画，下一镜就从右边入画。
- **应急**：剪映「画面 → 基础 → 镜像」翻转可以修正方向，但画面里有文字时不能用。
- **skill 字段（规划中）**：剧本元素写 `axis_side`、`screen_side`、`move_dir`，由审片器检查越轴（见 `review_rules.md`）。

## 对话场面

| 场面 | 规则 |
|---|---|
| **二人对话** | 结构：交代（全景或中景）→ 正反打 → 推到近景、特写到高潮 → 回到中景「休息」→ 退场。正反打每个镜头 2–4s，高潮近景 1.5–2.5s。对话开头 3s 内要有一个交代镜头；对话超过 30s，至少再交代一次。 |
| **人数对比** | 2 对 2 → 2 对 1 → 1 对 1，景别同时从中景 → 近景 → 特写，逐步逼近高潮；反过来用就是退潮。 |
| **三人对话** | 一人是「注意力主宰者」，他转头，戏的中心就跟着转移。用枢轴镜头（中间那个人的近景）掩护两侧人物换位。**不要双人镜头接双人镜头。** |
| **多人、围桌** | 先交代全景，再拆成几组，用内反拍交替，中途和结尾都回到全景。一人对群众讲长话时，每 10–15s 插一个听众镜头。 |
| **访谈** | 嘉宾看向记者（镜头旁边），不要看镜头。问话用 L-cut 盖到嘉宾的反应上。每 20–30s 插一个双人镜头或 B-roll。普通段落用中景，金句推到特写，然后回到中景。 |

- **声音拖过切点**：讲话人说到一半时切到听者的沉默反应，原声继续。听者的反应往往比讲话人的脸更有力。
- **插入 / 切出镜头的时长**：
  - 动作插入：从动作开始放到动作结束。
  - 静物、无表情的近景：≤ 2s。
  - 沉默聆听的反应：可以放 10s。
  - 反应镜头约 4s 最自然，≤ 2s 会显得突兀（剪辑的语法）。
- **视觉顿歇**：两段对话高潮之间，插 1–3s 环境镜头。
- **压缩时间**：开头和结尾保留完整，中段只留有意义的句子，直接硬切。
- **报道性对话提速**：常规变速 ≤ 1.25x，并开声音变调保护；抒情段不提速。

## 动作衔接

- **动作中切（最常用）**：一个连续动作拆成两个镜头，前一镜放约 1/3，后一镜放约 2/3。
  - 拍摄：后一镜开头要把动作完整重复一遍。
  - 剪映：在两段里找位置、方向一致的帧分割；**第二镜的入点比完全匹配点再往后 2–4 帧**，这样更顺（剪辑的语法）。
- **动作结束后切**：只用于同一视轴的推近（全景 → 近景），动作停下后留 2–3 帧再切。
- **视线剪**：头和眼停住的那一刻，切到他看见的东西（0–6 帧以内）。
- **起身**：眼睛接近画面顶边时就切，宁早勿晚。
- **出画**：眼睛离开画框就切，不留空镜；人物不能凭空从另一侧回到画面。
- **遮挡切**：前景路人横过、主体被遮住的那一帧，可以无痕地换景别或换时间。
- **强调一击**：一拳、一脚拆成中景 + 同轴近景两个镜头；近景开头补 0.1–0.2s 的 `shake`。
- **特写里动作显得更快**：插入的特写调到 0.8–0.9x。

## 运动镜头

- **起幅—运动—落幅**：运动镜头首尾各留 ≥ 0.3–0.5s 静止。运动接运动时，方向和速度一致；方向相反的两个摇镜不要直接相接。
- **人物先动，镜头后跟；镜头先停，人物再走一两步**，这样观众注意不到镜头在动。
- **推拉的情绪**：
  - 慢推 = 亲近、同情：3–6s 内放大到 1.10–1.15，速度 ≤ 5%/s。
  - 快推 = 震惊：≤ 0.5s 内放大到 1.3–1.4（`punch_in`）。
  - 慢拉 = 孤独、结束：`pull_out` 只放在段落最后一镜。
  - 同一段里反复的推拉，速度差 ≤ 10%。
- **数字放大等于变焦**：只能做极慢的「蠕动式」推近；想要更自然，叠一点轻微横移。
- **甩镜转场**：前一镜结尾和后一镜开头同向运动、同样模糊，用剪映的甩入 / 模糊转场，0.2–0.4s。
- **手持或 `shake`**：单段 ≤ 5s，只用在需要紧迫感的地方。素材本身是手持的，就不要再加 `shake`。

## 节奏

- **高潮前加速**：最后 4–7 个镜头时长依次缩短（每镜少 2 帧左右，最短 ≥ 8 帧），高潮镜头本身放长（≥ 2s）。平行剪辑同样越接近高潮越短。
- **分句手段**：
  - 淡入淡出：场与场之间；
  - 叠化：快叠是突然的转场，慢叠用来连接情绪；
  - 跳切：同轴连推 3 下，制造震惊；
  - 黑场：0.5–1.5s；
  - 定格 0.5–1s 后淡出；
  - 空镜开场或收尾。
- **场景从中性开始**：先给环境，或用开门、开灯、前景人物让开来揭示主体；场景的开头和结尾几乎总带一个动作。
- **主观视点三段式**：人物近景 → 他看到的画面 → 人物反应。

## 单机位模拟多机位（剪映落地）

| 目标 | 做法 |
|---|---|
| 近景 / 特写 | 复制同一段素材，近景缩放 1.4–1.6x，特写 2.0–2.5x（1080p 素材 ≤ 1.5x、4K ≤ 2x）；主体保持在画面同一区域 |
| 避免小跳 | **相邻两镜的缩放差 ≥ 1.25x（理想 ≥ 1.4x）**；1.03–1.15x 的「小跳」最难看（剪辑的语法） |
| 切点 | 落在动作帧（张嘴、点头、手势）或气口上，不要在完全静止时切 |
| 模拟反拍 | 画中画把听者放在角落（缩放 25–35%，放在主体视线的对侧），或做左右分屏（各 50%，视线相对） |
| 模拟推拉 | `push_in` / `pull_out` 关键帧，首尾留静止段 |

## 分场景

- **剧情短片**：全景交代 → 外反拍正反打 → 内反拍近景推到高潮 → 再交代 → 退场。严守轴线；对白用 J/L cut；不自动剪表演停顿（`keep_pauses`）。叠化只用于时间、地点、回忆和比喻。场景收尾用 `pull_out` + 淡出。
- **影视解说**：解说词是「动作」，原片是「证据或反应」。每个原片片段 1.5–4s，从动作起点或出画点截取；同一段解说里方向和轴线保持一致；换场景用黑场或叠化分句；讲到人物心理时插他的沉默反应。概念剪辑（靠并置产生含义）直接硬切。
- **Vlog**：
  - 用同一运动方向把两个地点「缝」起来：人物左出画、下一个地点右入画。
  - 新地点先给 1–2s 远景或空镜，或先给细节再拉开。
  - 换地点用声桥或 J-cut，跟拍镜头按起幅、落幅剪。
  - 空镜作顿歇；同类镜头连推 3 下可以做跳切开场。
