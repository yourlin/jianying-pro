# 镜头语言：景别、构图、角度、光线、焦点

来源：《镜头的语法》（Grammar of the Shot，汤普森、鲍恩，**用户提供的是试读节选**，第一到五章只有目录，相关条目按通行影视规范补全，标为「通行」）、《电影语言的语法》（阿里洪）。只提炼规则，没有复制原文。

每条写法：规则 → 拍摄时怎么做 → 剪映里怎么做 → skill 字段 / 能力。

## 景别

- **景别家族**（通行）：大远景交代环境 → 全景 → 中景 → 近景 → 特写 → 极特写。越近情绪越强，越容易出画、失焦。
  - 拍摄：每场至少「全景 + 中景 + 近景」三档。
  - 剪映：从中景裁成近景，画面 → 基础 → 缩放。**放大上限：1080p ≤ 130%，4K ≤ 200%**，再大会糊。
  - skill：剧本元素可写 `shot_size`，编译时换算成 scale（见 `staging.md` 的「单机位模拟多机位」）。
- **景别成对使用**，一场戏不超过 4 种景别（阿里洪）。
- **连续 4 个以上近景后，要回到一个中景或更宽的镜头**重新定场（剪辑的语法；竖屏口播可放宽到 6 个）。

## 构图

- **头顶空间宁少勿多**：留多了脸会下沉，说话时下巴出画。
  - 竖屏人像：**双眼在距画面顶部 30%–38% 处，头顶留 3%–8%，下巴不出画**。
  - 同一段口播的多个片段，缩放差 ≤ 3%、位置 Y 差 ≤ 2%，否则剪接时头会跳（刻意的 punch_in 除外）。
  - punch_in 放大时把锚点放在双眼，保持头顶留白一致（剪辑的语法）。
- **视线空间**：人朝哪边看，哪边多留空。人物放在三分线上，视线前方留约 2/3 画面。
  - 竖屏左右空间不够时，在视线方向放文字或插卡。
- **重要的放上半部**：观众先看上半部；人脸和商品不要放在下 1/3，那里会被字幕挡住。
- **地平线水平**：画面 → 基础 → 旋转 ±1°–3° 校正，同时缩放 ≥ 105% 遮住黑边。荷兰角（倾斜 10°–15°）只在悬疑、失衡的情绪下用。
- **前景人物（过肩镜头）**：肩膀占画宽 1/4–1/3；面对镜头的说话人占 2/3（阿里洪的外反拍）。
- **去掉干扰物**：脑后不能「长出」杆子或线条，屏幕和窗户会抢注意力。拍前绕主体看一圈；后期只能裁掉，或用蒙版压暗、虚化。

## 横屏素材进竖屏

| 方案 | 剪映做法 | 适合 |
|---|---|---|
| 铺满 | 缩放约 178%，位置 X 移到人脸（人脸中心 X 在 40%–60%）；人在走动时用位置关键帧跟随（`pan_left/right`） | 人物居中的素材 |
| 留边 | 缩放 100% + 背景填充模糊（`main.background`），上下空白放标题和字幕 | 横构图的风景、多人画面 |

**同一个视频只用一种方案。** 拍摄时就要出竖屏的横屏素材，人物尽量放在中间 1/3。

## 角度、焦距、光线

- **角度**：平拍客观，仰拍强势，俯拍弱小。口播机位放在眼睛高度，或略高 5°–10°。后期做不出角度变化。
- **焦距**：广角近拍人脸会让鼻子变大，拍特写要退远并换长焦；手持拍摄用广角更稳。变形后期无法修复。
- **焦点**：主体任何时候都要清晰；虚焦镜头后期救不回来，直接淘汰（需人工复核）。
  - 后期模拟浅景深：复制一层，背景层加模糊，主体层加圆形蒙版、羽化 30%–50%。
- **光线**：主光在 45° 方向，配补光和轮廓光；中景以上的景别要能看到眼神光。
  - 后期：人脸暗时用局部调色（`add_local_adjust`：圆形蒙版内亮度 +10、阴影 +15）；暗角 15–25 用来引导视线。
- **颜色分离**：深色衣服不要配深色背景。HSL：背景主色饱和度 -20 ~ -30，主体色 +10（`set_hsl`）。
- **同场景色调统一**：相邻镜头色温差 ≤ 5；肤色饱和度变化 ≤ +10。相邻片段平均亮度差 > 35% 要做调色匹配（剪辑的语法）。

## 拍摄覆盖（给剪辑留余地）

- **每个机位都把整段动作完整拍一遍**，方便在动作中间切换机位（重叠动作）。
- **开机后等 2s 再表演，表演完再停 2s**，剪辑时才有余量做转场和留气口。
- **多机位用拍手声打板**，剪辑时按声音峰值对齐，误差 ≤ 1 帧；来不及就在结尾补拍。
- **同一段话分两遍拍**（全景一遍、近景一遍），再多拍 3–5 个手部或环境的插入镜头（阿里洪）。
- **极特写**：动作要小、要慢，提前告诉被拍的人画面有多紧。
- **底噪（房间音）录 30s 以上**，用来填剪气口后的空隙（剪辑的语法）。
- **分镜表**：每个镜头写清景别、机位、角度、运动和时长，对应 skill 的剧本 → 分镜。
