# 节奏

## 剪气口

- **不要一刀切**：删口误、重复起句、「嗯 / 啊」填充音；保留自然换气和段落转折处的停顿。（freeform）
- 默认阈值（`analyze_footage.py --min-silence`）：
  - 紧凑：剪掉 ≥ 0.45s 的静音（国风规范；适合口播知识、带货）
  - 自然：只剪 ≥ 0.8–1.0s 的停顿；讲课类放宽到 1.5s，访谈收紧到 0.8s。（capcut-skill）
- 同一句说了几遍，保留最后一遍。（smartcut）
- 剪点吸附到词边界，前后各留 20–60ms 余量，避免吃字。（koubo）
- 倍速不是默认增强，默认 1.0；要加速先问用户。（koubo）例外：教程 / 演示录屏里超过 5s 的等待段（加载、生成、无旁白的长停顿）默认要处理，见下面「等待段」。

## 跳剪（jump cut）

- 口播、Vlog 里观众已经习惯跳剪，用来压缩时间。（StudioBinder、维基·跳接）
- 同一机位连续跳剪会「跳一下」很生硬。两种处理办法：
  - 剪点前后的画面交替用 100% 和 110–120% 缩放，做出「假景别」变化；
  - 用插卡、B-roll 盖住剪点。

  依据：30 度规则，即景别只差一点点的切换最突兀。（维基·30 度规则）

## 平均镜头时长（短视频，经验值）

| 场景 | 平均镜头 / 景别变化间隔 |
|---|---|
| 口播知识 | 3–6s；每 2–3 句换一次景别（假景别缩放）或插一条 B-roll |
| Vlog | 2–4s |
| 教程录屏 | 5–10s，跟着操作步骤走。**这是剪辑后的目标**：录屏原片常常一个镜头几十秒，要靠步骤标题、点击放大、加速 / 跳剪制造变化 |
| 带货种草 | 1.5–3s |
| 影视解说 | 2–4s，一句旁白一个镜头 |
| 卡点混剪 | 0.3–1s，对齐节拍 |
| 宣传片 / 预告（横屏） | 1–3.5s，中位约 1.6s；叙事段每 6–8 拍一刀，蒙太奇段每 2 拍一刀且等长 |
| 音乐视频（MV） | 1.3–3.2s，中位约 2s；按歌词行切；高潮段允许演唱长镜头，不加快 |

镜头越长越松弛，越短越紧迫。（维基·景别）宣传片和 MV 两行来自实测样本（横屏宣传片约 50s、产品歌曲 MV 约 110s）。

## 等待段（教程 / 演示录屏）

- 超过 5s 的等待（加载、生成、无旁白也无操作）**加速或跳剪**，不要原速保留。实测演示录屏样本里，等待段占时长一半以上，单段最长十几秒到近 2 分钟。
- 跳剪：只留等待的头尾各约 1s（看得出「在等」和「等到了」），中间剪掉。
- 加速：中间部分加速到约 2s，2–8 倍；8 倍还太长时，只加速前面一段，其余跳剪。
- 旁白停顿超过 5s 的操作段，补一张步骤字卡或加速。
- 成果展示可以用「快翻蒙太奇」：每页 0.2–1.5s。
- 编译器按场景 `pacing.wait` 处理（`scripts/script_compiler.py`），等待区间来自转写空档或剧本 `waits`。

## 卡点

- 默认每 2 拍切一次：每拍都切适合快闪段，每 4 拍（一小节）切适合舒缓段。（Easel）
- 卡点用硬切，强拍上加推近（`punch_in`）或白闪；不要每拍都切，只卡强拍和情绪转折点。（Easel、coach）
- 段落边界落在小节线或半小节线上；音乐从小节线进入，不从乐句中间开始。（promo）
- 蒙太奇段想要「整齐」：段内每个镜头同样的帧数（如 115 BPM 每 2 拍 = 31 帧 @30fps），而不是逐个吸到拍点上。
- 整段切点都比检测到的拍点早或晚同样的几帧（相位一致）也是卡拍，不要当成「不卡点」。

## 按歌词切（MV）

- 有人声的歌，切点跟着歌词走：一句歌词一个镜头，切在行首（或间奏前的行尾）。
- 比 1s 短的行（语气词、短呼喊）并进相邻镜头；没有歌词的间奏超过 4s，在拍点上补一刀。
- 高潮段不要因为能量高就切快，用演唱长镜头撑（2–8s）。
- 乐器特写可以 0.4s 左右连闪 2–3 个做点缀。
- 卡点混剪场景也可以按句切：`pacing.cut_on: "lyric"`（或剧本 `montage.cut_on`）。

## 衔接

- **动作接动作**：在动作进行到一半时切，前后镜头的方向和速度保持一致。（维基·Cutting on action）
- **匹配剪辑**：形状、颜色、运动方向对齐后再切。（维基·Match cut）
- **J-cut / L-cut**：下一镜头的声音提前 0.5–1s 进来，或上一镜头的声音延后 0.5–1s，常用于访谈、对话和段落过渡。（维基·J/L cut；时长为经验值）

## 国内经验

来源：diantuoyi《剪映口播音乐剪辑指南》、绘声绘影《Vlog 剪辑逻辑》、B 站专栏 cv17927684《10 个卡点剪辑技巧》。

- 口播段落之间留约 0.3s 静音来换气，不要剪得一口气不停。
- Vlog 用「两短一长」：特写 1–1.5s + 特写 1–1.5s + 全景约 3s。
- J-cut：下一镜头的声音提前约 1s 进来。
- 卡点不只卡重音。动作、物体运动、颜色、光线、二次构图（画中画）、运镜、变速转场都可以卡；高潮处用闪黑 / 闪白。
- 切点和音效首帧对齐，误差控制在 1–2 帧。
- 变速曲线：用「自定义」曲线做「加速 → 骤停 → 恢复」，常配合转场使用。装配器暂时只支持常规变速和 7 个预设，见 `motion_ops`。

## 剪映手册的实战案例节奏

来源：知乎《剪映从入门到精通》第 5 章。

| 案例 | 素材 → 成片 | 剪法 |
|---|---|---|
| 15s 日常 vlog | 5 段 × 10s → 每段 3s | 淡入淡出转场 0.5s；BGM 20%、淡入淡出 1s；清新滤镜 50%；右下角贴纸 + 弹跳 0.5s |
| 30s 美食教程 | 5 段 × 12s → 每段 6s | 右上角 1/4 画中画放食材特写；音效 15%（切菜、翻炒）+ 轻音乐 20%；步骤文字放画面下方；滑动转场 0.3s；锐化 +20、饱和度 +10 |
| 1min 旅行卡点 | 10 段 × 2–3s → 每段 0.5s 对齐鼓点 | 部分片段用曲线变速；每段闪白 0.1s；标题弹跳 0.3s；**导出 60fps** |
| 2min 知识口播 | 口播 + 图表 | 讲到每个方法时，图表画中画放右侧 1/3；要点加粗放下方；BGM 20%、口播 80% + 降噪；淡入淡出 0.5s；**每 30s 切换一次画中画或文字**，保持注意力；**章节之间 1s 黑屏 + 文字过渡**（如「方法一 → 方法二」） |
| 3min 剧情短片 | 多场景，每场景 30–60s | 场景切换统一用线性蒙版渐变（羽化 10）；人物走动用关键帧跟随（每 0.5s）；按情绪分场景调色（见 `grading.md`）；对话字幕按角色分颜色；BGM 伤感段 20%、温暖段 30% |
