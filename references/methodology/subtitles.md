# 字幕

## 断句（`storyboard_builder.split_transcript` 的默认值）

| 规则 | 数值 | 来源 |
|---|---|---|
| 每条字数 | 8–15 字，软上限 16、硬上限 18；英文约 26 字符 / 行、最多 2 行 | koubo、国风规范 |
| 每条时长 | 最长 3.2s；避免少于 4 字或短于 0.55s 的碎条 | koubo |
| 断点 | 词间停顿 ≥ 280ms 为强断点，160–280ms 为弱断点 | koubo |
| 开头几秒 | 每页 4–8 字、一行 | douyin-h3 |
| 连接词 | 「但是 / 所以」放下一条开头；下一条不以「的 / 得 / 地」开头 | koubo |
| 提前量 | 字幕比声音早 0.2–0.5s 出现更跟手（`subtitles.lead`） | coach、cutcli |
| 结尾 | 不超过下一句开始 | 国风规范 |

## 样式

- 正文字幕：白字 + 黑描边（任何背景都能读），居中；**字幕正文不加花字**，否则会降低可读性。（douyin-h3、国风规范）
- 竖屏字号下限：主字幕 ≥ 48px（剪映 size ≈ 8.0），副字幕 ≥ 38px（size ≈ 6.3）。换算：像素字高 ≈ size × 6.0（1920 画布）。（国风规范）
  - douyin-h3 的建议值（换算到 1080×1920）：≤7 字用 81px，8–9 字 75px，10 字 66px，超过 10 字就拆。
- 爆款风格：每条 ≤ 12 字、≤ 2s，每条一个高亮关键词，全片只用 1–2 种高亮色；入场用弹入或上滑，不用渐显。（cutcli）
- 双语：主语言在上、字号更大；副语言在下、字号小一档。（coach）
- 知识卡、字幕底：黑底，透明度 0.55，圆角 8。（cutcli）

## 位置（竖屏，剪映 transform_y）

- 主字幕 y ≈ -0.44，副字幕 y ≈ -0.58，下限 -0.68（再往下是平台文案区）。
- douyin-h3 给的字幕区是画面高度的 62–71%（约 y -0.24 ~ -0.42）。人脸偏下时字幕要上移，不要压嘴。
- 详见 [safe_area.md](safe_area.md)。

## 国内经验

来源：来画《视频文字排版 8 要点》、绘声绘影《字幕字号与题材配色》、adsturbo《电商视频字幕与 UI 安全区》。

- 单屏最多 2 行，每句只放一个信息点；字幕和口播同步，或提前 0.1s 出现。
- 关键词出现时，对齐音效或画面切点。
- 全片字体 2–3 种以内；只有底部字幕时只用 1 种。
- 字幕颜色优先黑白灰；避免高饱和亮色字、红底绿字、彩虹渐变。
- 静音观看：尽量让字幕和画面就能看懂，减少对旁白的依赖。
