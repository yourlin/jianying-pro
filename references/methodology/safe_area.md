# 安全区

## 竖屏 9:16（抖音 / 视频号 / 快手）

按画面高度和宽度的百分比，括号里是剪映的 transform_y / transform_x。

| 区域 | 位置 | 能放什么 | 来源 |
|---|---|---|---|
| 顶部状态区 | 高度 0–12%（y > 0.76） | 什么都不放 | douyin-h3 |
| 标题区 | 12.5–21%（y 0.58 ~ 0.75） | 标题、章节名 | douyin-h3 |
| 主视觉区 | 21–60%（y 0.20 ~ 0.58） | 插卡、点题大字（避开人脸） | douyin-h3 |
| 字幕区 | 62–71%（y -0.24 ~ -0.42）；国风规范用 -0.44 / -0.58 | 字幕 | douyin-h3、国风规范 |
| 底部文案区 | 72–100%（y < -0.68 最好什么都不放） | 平台标题、话题 | douyin-h3 |
| 右侧按钮区 | 宽度 82–100%（x > 0.64），高度 30–84% | 点赞、评论、分享按钮 | douyin-h3、国风规范 |

- 文字行宽 `max_line_width ≤ 0.70`，否则居中文字会伸进右侧按钮区。（国风规范）
- 最终在约 360×640 的手机尺寸下复查一次（看审片器对比图的缩略图）。（douyin-h3）

## 小红书 3:4

- 1080×1440，上下 UI 较少，但封面会被裁成 3:4，主体放在中间 80% 的区域（经验值）。（maxazure：要单独校验）

## 横屏 16:9（B 站 / YouTube）

- 字幕放在底部 10–15% 处，左右留白 ≥ 5%；右上角会有弹幕和水印，不放标题（经验值）。

## 国内经验（保守并集）

来源：databrush《竖屏视频发布前自检清单》、adsturbo、cardcrafter《抖音封面尺寸》。

- 竖屏 1080×1920：顶部留 14%（约 270px）、底部留 26%（约 500px）、右侧留 20%（约 216px）、左侧留 5%。
  - 抖音、快手实测值：顶部 8–10%、底部 18–22%、右侧 15–18%。
- 价格、CTA 不要和字幕共用一条基线。
- 封面：中央安全区 1080×1320，主标题 ≤ 8 个字、字号 ≥ 80pt。
- TikTok / YouTube Shorts 的 UI 布局和抖音接近（右侧按钮、底部文案），按上面的并集处理（经验值）。
