# 剪辑原则：六要素、剪点、转场、连贯、声音

来源：《剪辑的语法》（Grammar of the Edit，汤普森、鲍恩，全书）。
- 标【书】：书中原有的数值；
- 标【建】：按书中原则换算到短视频的建议值，需要用成片校准。

只提炼规则，没有复制原文。

## 流程

获取 → 整理 → 筛选 → 顺片 → 粗剪（宁长勿短）→ 精剪 → 锁定画面 → 混音 → 交付。

对应到 skill：剧本 → 编译分镜（顺片）→ 装配（粗剪）→ 审片器和剪映截图（精剪）→ 配乐和响度统一。

## 六要素（满足得越多，剪点越不显眼）

1. **信息**：每个新镜头都要带来新信息；不推进内容的镜头删掉。
2. **动机**：每一刀都要有理由，比如视线、动作、声音或节拍。
3. **构图**：相邻镜头构图太像，看起来就像跳切。对话镜头左右镜像：A 在左看右，下一镜 B 在右看左。
4. **角度**：同一主体的相邻镜头，机位至少差 30°【书】，或者景别明显变化。
5. **连贯**：动作、位置、道具、声音都要接得上。
6. **声音**：声音可以引出剪点，也可以掩护剪点。

## 剪点时机

| 情况 | 剪点 |
|---|---|
| 动作 | 在动作进行中剪，第二镜入点比完全匹配点再往后 2–4 帧【建】 |
| 视线 | 头和眼停住时，切到被看的东西（0–6 帧以内）【建】 |
| 起身 | 眼睛接近画面顶边时剪，宁早勿晚【书】 |
| 出画 | 眼睛离开画框就剪【书】 |
| 声音 | 可以在声音大的地方藏剪点，但不要滥用【书】 |
| 对白 | 反应镜头放在句子中间比放在句末自然；剧情片不剪表演停顿，新闻和短片可以剪【书】 |
| 时长 | 用一句话说完画面内容所需的时间；反应镜头约 4s，≤ 2s 显得突兀【书】 |

## 转场（四种含义）

- **切**：默认选择，用于连续动作、冲击、换信息。切不顺的地方，换成叠化也救不了【书】，只能换素材或插一个镜头。
- **叠化**：用于时间流逝、换地点、闪回、蒙太奇、情绪、比喻。
  - 时长默认 1s【书】，正常范围 0.4–2.0s【建】；< 0.3s 像闪帧，> 2.5s 就成了叠印。回忆段 1–2s。
  - 音频做同样长的交叉淡化【书】。
  - **对话正反打之间禁止叠化**【书】。
- **擦除 / 划像**：用于换时空、两个镜头没有关联、需要包装感的地方。
  - 要快：0.3–0.6s【建】，最长 0.8s，配「嗖」的音效【书】。
  - 方向跟画面里的运动一致；前景物体横过画面的那一帧，可以直接切，形成自然划像【书】。
- **淡入淡出**：只用在片头、片尾和段落边界，时长 0.5–2.0s；音量跟画面一起升降；切黑之前最好是远景【书】。
- **数量**：非硬切的转场总数 ≤ 段落数 + 1；口播每分钟 ≤ 2 个【建】。同一个场景内只用硬切，标了闪回、蒙太奇或时间跳跃的除外。
- **匹配剪辑**：形状、颜色、位置相近的两个镜头（比如车轮接车轮）。先用关键帧把两个主体对齐到同一位置，再叠化 0.8–1.5s。
- **概念剪辑**：靠并置产生含义（比如订婚接脚镣），直接硬切。适合影视解说。

## 跳切与 30° 规则

- 景别相同、角度差 < 30° 就是跳切。刻意的跳切可以当作创作手法，但要做得明显。
- **竖屏口播剪气口后**，同机位的相邻片段二选一：
  - 缩放完全不变，作为明确的跳切风格；
  - 在 1.0x 和 1.25–1.4x 之间交替。

  **1.03–1.15x 的「小跳」最难看**【建】。也可以用 1.5–4s 的 B-roll 把剪点盖住。
- 同一视轴上跳过 3 级以上景别（比如全景直接到特写），中间要插一个中景【书】。

## 连贯

- 越轴镜头要用特写或物件镜头隔开【书】；道具不连贯时插切出镜头掩盖【书】；观众关注的物体，位置也要连贯。
- 头顶留白在相邻镜头之间保持一致【书】。
- 不要从运动中的主体，切到同一主体的静止镜头【书】。

## 声音

- **声画互补**：画面出现机场，就补引擎声【书】。
- **环境声连续**：环境声单独一轨铺满整个场景，剪气口留下的空隙用底噪填【书】；同一场景里，环境声断档 ≤ 0.3s【建】。
- **音量随景别**：特写更响【书】。
- **拆分剪辑**：粗剪时声画同切，精剪时再错开【书】。
  - J-cut：下一镜的声音提前 0.2–0.8s 进来；
  - L-cut：上一镜的声音延续 0.3–1.0s；
  - 错开超过 1.5s 就成了音画错位【建】；
  - 换场景时可以用声桥（比如茶壶声接汽笛声）。
- **开头**：声音可以先于画面，但 30–60s 的广告要尽早出画面【书】。所以**短视频第 0 帧必须有画面，前 3s 内要出现人声或主体**【建】。
- **结尾**：音乐从结尾倒推对齐，让最后一小节落在最后一个镜头上，再淡出【书】；不允许配乐在中途被硬切断。
- **配乐不压人声**：人声段配乐至少低 12dB【建】，即装配器的 BGM volume ≈ 0.2。
- 去掉「嗯 / 啊」；有声音但没有口型的地方，用 B-roll 盖住【书】。

## 字幕与标题

- 字幕卡停留约等于读三遍，多数 3–10s【书】；标题卡和人名条停留 ≥ max(2s, 字数 × 0.4s)、≤ 10s【建】。
- 人名条用叠化入出，只在人物第一次出现时给一次【书】。

## 剪辑师常见错误（自查清单）

1. 用转场掩盖剪不顺的地方。
2. 用了虚焦镜头。
3. 画面明暗反复跳变。
4. 画框切掉半张脸，或背景物「长在头上」。
5. 剪断一个本身完整的好镜头。
6. 太早用特写，稀释了高潮。
7. 连续几个特写后不回远景。
8. 新场景没有定场镜头。
9. 新人物没有给特写。
10. 剪得太久没有用「新眼睛」复看。审片器和剪映截图承担这个角色。

## 分场景

- **竖屏口播**：
  - 句间保留 0.15–0.3s 呼吸，> 0.6s 的静默剪掉；
  - 第 0 帧直接出画面，不做淡入；
  - 默认用中近景或特写，每一章给一次宽景重新定场；
  - 句与句之间只用硬切，章与章之间用 0.3–0.5s 叠化或擦除。
- **Vlog**：
  - 新地点先给 1–2s 远景或空镜，或先给细节再拉开；用环境声交代地点；
  - 换地点用声桥或 J-cut；压缩时间用叠化或插入镜头。
- **剧情短片**：
  - 定场 → 双人 → 正反打 → 高潮特写；
  - 严守轴线，对白用 J/L cut，不自动剪表演停顿；
  - 场景收尾用 `pull_out` + 淡出。
