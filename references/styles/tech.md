# 风格规范：科技

**适合**：数码、AI、编程、科普、产品发布。**关键词**：深色、冷色、发光、故障、数据感。克制是关键，避免满屏霓虹。（maple、promo）

## 版式

- 安全区、字幕位置按 `methodology/safe_area.md`；插卡位置按 `methodology/inserts.md` 的人脸避让。
- 信息卡用深色半透明底（黑色 alpha 0.55、圆角）+ 一个主色描边，像 UI 面板。
- 数字、参数放大强调（hero 大字），单位缩小。

## 字号

同通用规则：主字幕 size 9.0–9.5，副字幕 ≥ 6.3，标题 11–16，参数大字 18–24。

## 调色

- 滤镜：冷蓝 / 青橙电影 / 赛博朋克（强度 50–70%）
- 调节：色温 -10 ~ -20，对比度 +8，饱和度 -5

## 配色

主色青 `#2BD9FE`（关键词、描边）、背景深灰 `#0D1117`、辅助紫 `#7C5CFF`（少量）、警示橙 `#FF8A00`（仅用于对比 / 风险）。

## 节奏

- 镜头 2–4s；参数揭晓用 `punch_in` + 音效（叮 / 电子音）。
- 开场可以用扫描光条特效 + 标题，3s 内结束。
