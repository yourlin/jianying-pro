# 风格规范：古韵 / 国风（竖屏口播）

本文件是**硬约束**，不是建议。装配脚本只能从下列清单中选素材；要加新东西先改本文件。
所有数值针对 1080×1920 竖屏画布。

## 1. 画幅铁律（最容易犯的错）

| 规则 | 说明 |
|---|---|
| **禁用横版素材作为画面主体或横幅** | 16:9 的卷轴、水墨山水、片头片尾素材放进竖屏只能是窄条，既丑又无意义。只有做"全屏背景虚化垫底"时才可用，且必须压上内容 |
| 主视频必须全屏 | 竖屏源素材 1080×1920，`scale = 1.0`，不留黑边 |
| 素材方向先验证 | 入选前必须 `ffprobe` 确认宽高比；竖屏项目优先选 9:16 或正方形素材 |
| ⚠️ skill 已知坑 | jianying-pro 的标准化器会把竖屏硬转 1920×1080。先自行转码放进 `<源目录>/__jycache__/<名>.__jy_norm__.mp4` 绕过 |

## 2. 安全区与版式

```
y 轴（剪映 transform_y，+ 为上）         画面占比
+1.00 ┄┄┄ 画布顶 ┄┄┄                    0%
+0.80  ✗ 顶部状态区（勿放内容）          0–9%
+0.62  ─ 标题上限 ───────               ~19%
+0.34  插卡中心（主要内容区）            33%
 0.00  画面中心 / 人脸                   50%
-0.44  主字幕（中文）                    72%
-0.58  副字幕（英文/译文）               79%
-0.68  ─ 字幕下限 ───────               84%
-1.00  ✗ 底部文案区（平台 UI）           84–100%
```

- **左右**：留白 ≥ 6%。文字 `max_line_width ≤ 0.70` —— 超过 0.72 时居中文字会伸进右侧按钮区（x > 0.86）。
- **右侧 x > 0.86、y 0.30–0.84** 是点赞/评论/分享按钮区，任何文字和图卡都不得进入。
- 人脸所在的画面中部（y −0.25 ~ +0.25）不放图卡，图卡统一落在 y ≈ 0.34 的上三分之一。

## 3. 字号下限（短视频可读性）

换算：`像素字高 ≈ size × 6.0`（1920 画布）。

| 角色 | size | ≈px | 下限 |
|---|---|---|---|
| 主标题 / Hero 大字 | 11–24 | 66–144 | — |
| 主字幕（中文） | **9.5** | 57 | ≥ 8.0 (48px) |
| 副字幕（英文译文） | **6.8** | 41 | ≥ 6.3 (38px) |
| 图卡标注 / 词汇卡 | 9–11.5 | 54–69 | ≥ 8.0 |

英文超过 26 字符自动折行，最多 2 行。

## 4. 字体三件套（全部免费）

| 用途 | 字体 | 理由 |
|---|---|---|
| 标题 / Hero 大字 | **挥墨体** | 毛笔挥洒感，适合单字和短标题 |
| 标注 / 词汇卡 / 中文字幕 | **启功行楷** | 行楷清秀易读，长句不糊 |
| 英文副字幕 | 系统默认无衬线 | 与中文书法形成对比，不抢戏 |

备选书法字体（均免费）：古风小楷、柳公权、方正王铎行草、喜鹊梅花楷、惊鸿体。

| 水墨晕染（转场） | VIP | 遮盖剪点，0.8s | 不要连续多个剪点都用，3 次以上会腻 |
| 水墨（转场） | 免费 | 同上的免费替代 | |
| 水墨竹叶（特效） | VIP | 结尾氛围，**≥ 5s** | |

**特效三条铁律**：① 必须有叙事功能（遮剪点 / 标记段落 / 收尾），纯装饰不加；② 时长 < 3s 的氛围特效一律不用，观众只会看到一团莫名的墨；③ 全片特效不超过 3 处。

## 7. 配乐

- 曲目：**春满长桥**（ID `7376298242855946291`，国风，免费，142s）
- 音量 **0.22**，淡入 1.2s / 淡出 2.5s
- 备选：古典 中国风 古韵 悠扬（`7491916574502324275`）、中国风 讲述传说故事（`7377872086175320083`）
- **所有覆盖层素材 `volume = 0`** —— B-roll 自带音效会和旁白/BGM 打架

## 8. 节奏

- 开头 3 秒必须真人出镜建立信任，不加插卡
- 静音气口 ≥ 0.45s 的剪掉，剪点用转场或插卡遮盖
- 插卡时长 6–8s（短于 3s 看不清内容，长于 10s 会盖太久人脸）
- 教学/口型段落不加插卡，让观众看脸
- 词汇卡点用语音识别的**词级时间戳**，不要平均分配时间

## 9. 配色

墨黑 `#1a1a1a`、宣纸白 `#f5f1e8`、朱红 `#c8372d`（仅用于 Hero 点题）、金箔 `#c9a84c`（仅用于标注）。
字幕统一白字 + 黑描边（描边宽度 0.08），任何背景上都能读。
