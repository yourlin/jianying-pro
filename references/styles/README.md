# 风格规范

引导模式第 ② 步选风格，第 ③ 步按风格的**白名单**挑素材（出封面对比图给用户选），第 ④ 步按风格的**硬约束**写分镜。

| 风格 | 文件 | 适合 |
|---|---|---|
| 国风古韵 | [guofeng.md](guofeng.md) | 传统文化、汉字、诗词、非遗、古风 |
| 科技 | [tech.md](tech.md) | 数码、AI、编程、科普、产品发布 |
| 清新文艺 | [fresh.md](fresh.md) | 生活方式、读书、旅行、治愈系 Vlog |
| 综艺活泼 | [variety.md](variety.md) | 搞笑、萌宠、美食、综艺剪辑、情绪表达 |
| 商务简约 | [business.md](business.md) | 职场、财经、企业宣传、知识付费 |

每个风格文件都有这几块：画幅与版式、字号、字体、花字 / 文字模板、转场与特效、调色、配乐、配色、节奏、**候选关键词**（给 `preview_assets.py` 搜素材用）。白名单里的素材名都来自本机面板索引，换了剪映版本后用 `asset_search.py` 核对一下。

通用规则（安全区、字幕、插卡人脸避让、运镜、音频）见 `../methodology/`，风格文件只写和通用规则不同的部分。
