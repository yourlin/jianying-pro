# 场景：影视解说

**适用**：影视剧、纪录片二创解说（原片 + 旁白）。skill 已有长视频解说工具：`scripts/movie_commentary_builder.py`（见 `rules/generative.md`）。
**建议时长**：1–5min。

## 结构模板

| 段落 | 时长 | 用途 | 画面 |
|---|---|---|---|
| 冷开场 | 0–8s | 最有冲突的一幕 + 悬念式旁白 | 原片高光片段，片名卡 |
| 交代 | 8–20% | 人物、背景 | 人物特写定格 + 人物名字条 |
| 剧情推进 | 60% | 一句旁白一个镜头 | 原片片段，2–4s 一切 |
| 高潮 / 反转 | 10% | 情绪顶点 | 原声主导，旁白退后 |
| 结尾 | 5–10% | 观点 / 下期预告 | 定格 + 金句 |

## 要点

- 先剪画面，后配旁白；每个片段先定好由谁主导声音：原声 / 动作声 / 沉默 / 旁白。（recap）
- 旁白只在必要时出现；高潮段让原声主导，BGM 压低。
- 不要在原片的转场中间再切一刀；接点前后检查 0.5–1s。（recap）
- 竖屏裁切时人脸放在上 1/3；横版原片可以用「背景虚化垫底 + 原片居中」。
- 版权：只用于评论、解说等合理使用的范围，原片单段不要太长（经验值，提醒用户自行确认平台规则）。

## 引导问题（第二轮）

1. 旁白来源：用户自己录 / TTS 配音（选音色）
2. 画幅：竖屏（原片居中 + 背景虚化）/ 横屏
3. 风格：悬疑紧张 / 温情 / 吐槽搞笑
4. 字幕：旁白字幕 / 旁白 + 原片台词字幕
