# 场景：音乐视频（MV）

**适用**：产品歌曲、品牌歌曲、翻唱 MV。有完整的歌和歌词，画面是演唱、乐队、乐器、产品画面的组合。
**建议时长**：一首歌，60–240s。
**依据**：实测产品歌曲 MV 样本（约 110s、横屏）：镜头中位约 2.0s，P25–P75 为 1.3–3.2s，每分钟约 24 个镜头；约 65% 的切点和歌词换句重合。

## 结构模板

| 段落 | 用途 | 剪法 |
|---|---|---|
| 片名 | 歌名大字压在乐队 / 主角全景上 | 单镜头 3–4s 不切 |
| 主歌 | 主唱交替 + 合唱 / 乐器 | **一句歌词一个镜头** |
| 副歌 | 产品 / 主题画面插入 | 产品 UI 插入 2–4s，进出用快速推近 / 拉远 |
| 高潮 | 情绪顶点 | 演唱长镜头撑，**不加快切速**（实测高潮段反而切得更慢） |
| 尾声 | 收束 | 片尾短闪黑收 |

## 要点

- **按歌词行切，不按拍切**：切点放在歌词行的开头（或间奏前的行尾）。比 1s 短的行并进相邻镜头；没有歌词的长段（间奏）超过 4s 时在拍点上补一刀。场景 `pacing.cut_on = "lyric"`。
- **高潮段允许长镜头**：高潮段镜头最短 2s、最长 8.5s，不要因为能量高就切快。
- **乐器特写可以闪切**：0.4s 左右连闪 2–3 个做点缀，在剧本里单独写一段。
- **推拉只用在切到产品 UI 的时候**：段落写 `ui_insert: true`，编译器在进出处加快速推近 / 拉远；其他段落的推拉会被跳过。
- **全片统一调色**：同一个 LUT / 滤镜，插入的产品 UI 也调成同一色调。低调光的「欠曝」是风格，不是问题。
- **字幕**：底部小号歌词，一句一条。
- 转场约 90% 硬切。

## 歌词时间

`montage.lyrics` 给带时间的歌词（音乐时间，秒）：`[{start, end, text}]`，或者带 `transcript` / `segments` 的 JSON（比如对歌曲跑 `analyze_footage.py` 的转写，校对后使用）。段落 `time` 可以直接写歌词片段，比如 `{"from": "第一句歌词", "to": "最后一句"}`。

想要卡点混剪的快节奏、但按句子切，用 `beat_montage` 场景加 `montage.cut_on: "lyric"`。

## 引导问题（第二轮）

1. 歌曲和歌词时间：有带时间的歌词（lrc / srt / json）/ 先转写歌曲再校对
2. 按什么切：按歌词行（默认）/ 按节拍
3. 要不要插入产品画面：要（进出推拉）/ 不要
4. 统一色调：复古暖色 / 冷色科技 / 保持原色
