# 场景：口播知识

**适用**：单人对镜头讲知识、观点、教学（`analysis.json`：说话占比 > 60%，镜头切换 < 4 次 / 分钟）。
**建议时长**：30–90s；素材更长时先问用户要不要拆成多条。

## 结构模板（60s 版本，按比例伸缩）

| 段落 | 时长 | 用途 | 画面 |
|---|---|---|---|
| 钩子 | 0–3s（5%） | 问题 / 反差 / 结论先行 | 真人近景，标题大字；**不加插卡** |
| 点题 | 3–8s（8%） | 说清今天讲什么、为什么值得看 | 点题大字（hero）或章节标题 |
| 干货 1–3 | 8–50s（70%） | 每个要点 10–20s：观点 → 证据 / 例子 | 插卡 / B-roll 对应关键词；每 2–3 句一次景别变化 |
| 总结 | 50–55s（8%） | 一句话收束 | 真人，金句大字 + `punch_in` |
| CTA | 55–60s（9%） | 评论区提问 / 关注 | CTA 文字停 ≥ 3s，结尾氛围特效（可选，≥ 3s） |

依据：koubo、maple、douyin-h3 的「问题 → 背景 → 观点证据 → 例子 → 结论 CTA」；cutcli 的 60s 模板（0–2s 标题，3 个要点约 10 / 18 / 20s，最后 10s 总结 + CTA）。

## 要点

- 剪气口：默认紧凑（≥ 0.45s），讲课类可选自然（≥ 1.0s）。
- 单机位跳剪：剪点前后用 100% ↔ 110–115% 交替缩放；或者用插卡遮住剪点。
- 运镜：要点开头 `push_in`，金句 `punch_in`；全片 4–8 处。
- 插卡：必须先看 `faces.card_zones`。近景自拍、人脸占满画面时，问用户用哪种插卡方式（见 `methodology/inserts.md`）。
- 顶部可以放一个章节标题，章节切换要跟着说话内容走。（douyin-h3）
- 教学跟读段（发音、口型）不加插卡。

## 引导问题（第二轮）

1. 字幕：中文 / 双语 / 外语 + 中文翻译
2. 节奏：紧凑（剪 ≥ 0.45s 气口）/ 自然（剪 ≥ 1s 停顿）
3. 包装：克制 / 适中 / 丰富
4. 插卡方式（`card_zones` 为空时）：整屏切图 / 真人小窗 / 间隙短暂压屏
