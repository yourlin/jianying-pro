# 场景：Vlog

**适用**：生活记录、旅行、探店，多段素材，口播不多（镜头切换 ≥ 4 次 / 分钟）。
**建议时长**：30s–3min。

## 结构模板（30s 版本）

| 段落 | 时长 | 用途 | 画面 |
|---|---|---|---|
| 开场 | 0–2s | 最好看的一个镜头 + 标题（地点 / 主题） | 远景或高光片段，标题文字模板 |
| 段落 1–3 | 2–28s，每段 8–10s | 按时间或地点分段 | 每段开头一个建立镜头（远景）+ 细节特写；段落之间擦除 / 叠化转场；时间或地点标签字幕 |
| 收尾 | 28–30s | 情绪收束、下期预告 | 拉镜（`pull_out`）或背影远景 |

依据：cutcli 的 30s Vlog 模板（字幕 transform_y = -0.7，三段带时间标签）；Vlog 景别「全景 / 中景 / 特写交替」。

## 要点

- 镜头 2–4s；每段 3–5 个镜头，景别交替（远 → 中 → 近）。
- 音乐主导：BGM 约 0.55，有口播时压到 0.25 以下；段落切换卡在小节线。
- 没有拍运镜的固定镜头，可以加 `push_in`（1.0 → 1.06），或用 `pan_left` / `pan_right` 平移制造流动感。
- 调色统一：全片用同一个滤镜，强度 60–80%。
- 转场：段落之间才加，段内硬切。

## 引导问题（第二轮）

1. 情绪基调：治愈慢节奏 / 轻快 / 热血燃
2. 分段方式：按时间 / 按地点 / 按事件
3. 口播段落：保留原声 / 只用音乐 / 配旁白（TTS）
4. 字幕：只有地点 / 时间标签 / 全程字幕
