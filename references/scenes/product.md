# 场景：带货种草

**适用**：产品介绍、开箱、好物推荐。
**建议时长**：15–45s。

## 结构模板（30s 版本）

| 段落 | 时长 | 用途 | 画面 |
|---|---|---|---|
| 钩子 | 0–3s | 痛点 / 效果对比 / 价格反差 | 使用效果特写 + 大字标题 |
| 产品亮相 | 3–12s | 是什么、长什么样 | 产品图轮播，质感微距，`push_in` |
| 卖点 1–3 | 12–24s，每个 4s | 一个卖点一个画面 | 卖点大字 + 使用演示；卖点出现时加音效 |
| 证明 + CTA | 24–30s | 效果证明、价格、下单引导 | 前后对比 / 价格卡，CTA 停 ≥ 3s |

依据：cutcli 的 30s 产品模板；promo 的「痛点 → 转折 → 证明 → 号召」；jianying-skills：一条片子不要塞进所有卖点。

## 要点

- 镜头 1.5–3s，节奏快；卖点字幕每条 ≤ 12 字，每秒 5–10 词。（TikTok、cutcli）
- 卖点出现时 `punch_in` + 音效（叮）。
- 价格、优惠用高亮色，全片高亮色不超过 2 种。
- 注意平台广告规范：不用「最好、第一、100%」等绝对化用语（经验值）。

## 引导问题（第二轮）

1. 主打卖点（最多 3 个，让用户选或写）
2. 风格：真实测评 / 精致种草 / 促销冲量
3. 有没有价格 / 优惠信息
4. 配乐：轻快流行 / 高级感纯音乐 / 动感电子
