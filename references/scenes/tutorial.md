# 场景：教程录屏

**适用**：软件操作、屏幕录制、手把手教学。
**建议时长**：60s–5min；按步骤拆章节。

## 结构模板

| 段落 | 时长 | 用途 | 画面 |
|---|---|---|---|
| 结果先行 | 0–5s | 先展示做完的效果（钩子） | 最终效果画面 + 标题 |
| 步骤 1–N | 每步 10–40s | 一步一段，每段开头有步骤标题 | 录屏全屏；点击位置局部放大；步骤编号标签 |
| 总结 | 最后 5–10s | 回顾要点 / 常见问题 | 要点列表卡 |
| CTA | 3s | 关注 / 下期 | 文字卡 |

## 要点

- 点击位置局部放大：默认 1.75 倍、持续 1.2s、0.16s 淡入淡出，配一个简短标签。（maxazure）skill 自带录屏智能变焦：`rules/recording.md`。
- 镜头（步骤）时长 5–10s，跟着操作走，不卡音乐节拍。
- 人像小窗放角落（scale 0.3），不挡操作区。
- 删掉加载等待、无效鼠标移动；等待处可以加速（先问用户）。
- 字幕要完整（教程观众会静音看），关键术语高亮。

## 引导问题（第二轮）

1. 有没有人像出镜：无 / 角落小窗 / 开头结尾出镜
2. 放大方式：自动按点击放大（需要录屏事件文件）/ 手动指定位置 / 不放大
3. 等待段：剪掉 / 加速 / 保留
4. 字幕：全程字幕 / 只有步骤标题
