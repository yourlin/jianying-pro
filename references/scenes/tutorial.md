# 场景：教程录屏

**适用**：软件操作、屏幕录制、手把手教学。
**建议时长**：60s–5min；按步骤拆章节。

## 结构模板

| 段落 | 时长 | 用途 | 画面 |
|---|---|---|---|
| 结果先行 / 集标题 | 0–5s | 先展示做完的效果（钩子）；系列教程可以是集标题页（第 N 集 · 主题）或上集回顾，停 3–4s 不切 | 最终效果画面 + 标题 |
| 步骤 1–N | 每步 10–40s | 一步一段，每段开头有步骤标题 | 录屏全屏；点击位置局部放大；步骤编号标签 |
| 总结 | 最后 5–10s | 回顾要点 / 常见问题 | 要点列表卡 |
| CTA | 3s | 关注 / 下期 | 文字卡 |

## 要点

- 点击位置局部放大：默认 1.75 倍、持续 1.2s、0.16s 淡入淡出，配一个简短标签。（maxazure）skill 自带录屏智能变焦：`rules/recording.md`。
- 镜头（步骤）时长 5–10s 是**剪辑后的目标**，跟着操作走，不卡音乐节拍。录屏原片常常一个镜头几十秒（实测演示录屏样本单段最长近 2 分钟），要靠步骤标题、点击放大、加速 / 跳剪制造变化。
- **超过 5s 的等待（加载、生成、无旁白的长停顿）一律处理**：默认跳剪（只留头尾各 1s，`pacing.wait.mode = "cut"`），也可以加速到约 2s（`"speedup"`，2–8 倍）。剧本 `waits_mode` 可以改成 `加速` / `保留`。没有旁白的录屏，在剧本 `waits` 里给等待区间，或直接传 `quality_review` 报告（读 `dead_zones`）。
- 旁白停顿超过 5s 的操作段，补一张步骤字卡（`label`）或加速。
- 成果展示可以用快翻蒙太奇：每页 0.2–1.5s。
- 人像小窗放角落（scale 0.3），不挡操作区。
- 删掉无效鼠标移动。
- **默认加轻 BGM**（风格默认配乐，音量 0.12）；用户明确不要时剧本写 `"bgm": false`。实测演示录屏样本全片无声，是最需要补的一项。
- 字幕要完整（教程观众会静音看），关键术语高亮。横屏字幕放在底部深色条里（transform_y 约 -0.85，深色半透明底、不加描边）。

## 引导问题（第二轮）

1. 有没有人像出镜：无 / 角落小窗 / 开头结尾出镜
2. 放大方式：自动按点击放大（需要录屏事件文件）/ 手动指定位置 / 不放大
3. 等待段（超过 5s）：跳剪（只留头尾）/ 加速 / 保留
4. 字幕：全程字幕 / 只有步骤标题
5. 背景音乐：加轻 BGM（默认）/ 不要
