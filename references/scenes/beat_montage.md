# 场景：卡点混剪

**适用**：多段素材 + 节奏感强的音乐，没有或很少口播（镜头切换 ≥ 8 次 / 分钟，或用户明确要卡点）。
**建议时长**：10–30s，最长不超过音乐的一段（主歌或副歌）。

## 结构模板

| 段落 | 用途 | 剪法 |
|---|---|---|
| 前奏 | 铺垫情绪 | 每 4 拍（一小节）切一次，镜头偏慢 |
| 主歌 | 展开 | 每 2 拍切一次 |
| 副歌 / 高潮 | 爆发 | 每拍切，强拍加 `punch_in` / 白闪 |
| 尾声 | 收束 | 拉镜或定格，跟音乐结尾对齐 |

依据：Easel（默认每 2 拍切；每拍适合快闪，每 4 拍适合舒缓）；promo（段落边界落在小节线，节拍一致性 ≥ 0.9 的曲子最适合快切）。

## 要点

- 镜头 0.3–1s。动作方向保持一致，用「动作接动作」衔接。
- 硬切为主，只在强拍加效果；不要每拍都加特效。
- 节拍点：用剪映的「踩点」功能，或者用户提供的节拍时间；skill 不能自动听歌，选曲后要请用户确认节拍。
- BGM 0.8–1.0，素材原声全部静音（除非有特意保留的音效）。

## 引导问题（第二轮）

1. 音乐：用户提供 / 从曲库推荐（按情绪）
2. 切点密度：舒缓（4 拍）/ 标准（2 拍）/ 快闪（每拍）
3. 结尾：定格 + 文字 / 拉镜淡出
4. 有没有标题文字
