# 场景：剧情短片

**适用**：有人物、对话和场景切换的短剧、微电影、故事类视频（多场景素材，有对白）。
**建议时长**：1–5min。
来源：知乎《剪映从入门到精通》5.5 节（3 分钟剧情短片案例），以及 `methodology/` 的通用规则。

## 结构模板

| 段落 | 占比 | 用途 | 剪法 |
|---|---|---|---|
| 开场 / 悬念 | 10% | 交代人物，或抛出冲突 | 建立镜头 + 人物特写；片名卡 |
| 发展 | 35% | 关系和事件推进 | 对话段用正反打（两人交替）；每个场景 30–60s |
| 转折 | 20% | 冲突、分离 | 冷色调（色温 -10、饱和度 -10）；节奏放慢 |
| 高潮 / 重逢 | 25% | 情绪顶点 | 原声主导；BGM 渐强；推近特写 |
| 结尾 | 10% | 余韵 | 拉镜或定格 + 字幕 |

## 要点

- **场景切换统一用一种转场**，比如线性蒙版渐变（羽化 10），保持画面统一。
- **按情绪分场景调色**：
  - 回忆 / 青春：暖，色温 +10；
  - 伤感：冷，色温 -10、饱和度 -10；
  - 温暖：对比度 +15，用电影感滤镜。

  详见 `methodology/grading.md`。
- 对话字幕按角色分颜色；对话 80%，BGM 20–30%，随情绪调整。
- 人物走动可以用关键帧做镜头跟随（每 0.5s 调一次位置）。
- 动作接动作、J-cut / L-cut 让对话更顺（见 `methodology/pacing.md`）。
- **先写分镜脚本再拍**，后期会省很多事。

## 引导问题（第二轮）

1. 情绪基调：温情 / 悬疑 / 喜剧 / 伤感
2. 对话字幕：按角色分颜色 / 统一样式
3. 场景转场：统一蒙版渐变 / 硬切 / 叠化
4. 片名和片尾：要 / 不要
