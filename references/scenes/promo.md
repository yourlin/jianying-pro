# 场景：宣传片

**适用**：游戏 / 产品 / 活动的宣传片、预告片。横屏为主，纯 BGM、没有旁白，多段实机或产品画面。
**建议时长**：30–90s，常见约 50s。
**依据**：实测宣传片样本（约 50s、横屏、中英两版）：镜头中位约 1.6s，P25–P75 为 1.0–3.5s，每分钟约 27 个镜头。

## 结构模板（50s 版本）

| 段落 | 时长 | 用途 | 剪法 |
|---|---|---|---|
| 标题卡 | 0–3.8s | 片名 + 副标题 + slogan，压在压暗的画面上 | 一个镜头不切；0.2s 出大字；叠化进出 |
| 故事 | 约 7s | 世界观 / 背景 / 角色 | 叙事段每 6–8 拍一刀 |
| 高光 | 约 5s | 核心爽点、最强画面 | 每 4 拍一刀，能量开始抬升 |
| 蒙太奇 | 约 6s | 同类内容快速轮播（关卡 / 场景 / 角色） | **每 2 拍一刀，镜头等长**（同样的帧数）；全片最密的一段 |
| 卖点 | 约 20s | 系统 / 功能逐个展示 | 每个卖点 1.5–3.5s，复杂 UI 可以单镜头放长；一个卖点一张标签卡 |
| CTA 结尾卡 | ≥ 3s | Logo / 二维码 / 立即体验 | 叠化进入，停 ≥ 3s，跟音乐结尾对齐 |

能量曲线按「低 → 中 → 高」走，最密的蒙太奇段放在中段。

## 要点

- **钩子是标题卡**：0 秒出大字，音乐 0.3s 内进来，标题卡停 3–4s 不切。这不算「钩子偏弱」，见 `../methodology/hook.md`。
- **切点按拍**：BGM 先跑 `beat_detect.py`。叙事段每 6–8 拍、卖点段每 4 拍、蒙太奇段每 2 拍。切点吸到拍点上，整段一致地提前或滞后几帧也算卡拍。
- **转场**：约 70% 硬切。叠化只用在开头标题卡和结尾卡（0.3–1s）；段落（章节）之间最多 1 次闪黑 / 闪白。
- **字幕用标签卡，不逐句出**：每个卖点一张左下角标签卡，主标题 + 小字副标题（多语言时副标题放另一种语言），3–5s 换一次。
- **多语言版本共用一条时间线**：只换文字，切点、转场、音乐都不动。剧本里给元素写 `i18n` 或在 `translations` 里写对照表，编译时加 `--lang en`。
- **色调按段落检查**：段与段之间换配色（关卡色 / 主题色）是有意的，只在同一段内部检查色调跳变（场景 `continuity.mode = per_section`）。
- 暗色美术风格的「欠曝」、片尾 CTA 卡的静止都是有意的，审片时不要当问题。
- BGM 0.8–1.0，素材原声静音（特意保留的音效除外）。

## 剧本写法（混剪模式）

```jsonc
{
  "scene": "宣传片", "format": "横屏", "style": "tech",
  "montage": {"music": "bgm.mp3", "beats": "bgm.beats.json", "clips": "clips/", "duration": 50},
  "beats": [
    {"id": "S01", "purpose": "标题卡", "time": [0, 3.8], "clips": ["clips/title_bg.mp4"],
     "elements": [{"kind": "hero", "text": "片名", "sub": "副标题 · slogan"}]},
    {"id": "S04", "purpose": "蒙太奇", "time": [16.3, 22.5], "clips": ["..."],
     "elements": [{"kind": "label", "text": "七大主题场景", "sub": "Seven themed stages"}]},
    {"id": "S05", "purpose": "卖点", "time": [22.5, 46.6], "transition": "chapter", "elements": [ ... ]},
    {"id": "S06", "purpose": "CTA", "time": [46.6, 50], "elements": [{"kind": "end_card", "title": "立即体验"}]}
  ]
}
```

段落 `purpose` 对上场景段落名后，自动取这一段的切速（`cut_every_beats`）、是否等长、进出转场；剧本段落里写同名字段可以覆盖。

## 引导问题（第二轮）

1. 配乐：用户提供 / 从曲库推荐（按情绪）
2. 要展示哪几个卖点（按顺序）
3. 要几个语言版本：只要中文 / 中文 + 英文 / 更多
4. 结尾卡：Logo + 立即体验 / Logo + 二维码 + 立即体验
